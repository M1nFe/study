**38주차 · 불확실성과 사람이 다시 볼 표본**

실제 날짜: ______ ~ ______ · 상태: 미시작 · 실험 숙련: 미평가. 2026-10-01 개정 계획이며 아직 수행한 결과가 아니다.

**이번 주 질문.** 모델의 확신이 높으면 측정을 그대로 사용해도 되는가?

**읽을 자료와 범위.** CAL 원저; MSMB 2·14장; 실제 실패 사례. 약어·공식 링크는 [실험 자료 목록](../references/wetlab.md)과 [기존 교재 목록](../references/books.md)에 있다. 번호 없는 범위는 목차·색인에서 찾을 주제명이며 검증한 절 번호가 아니다. 교재에서 원리를 읽고, 연구실 SOP와 실제 사용 제품의 현행 매뉴얼에서 조건을 대조한다. 실험 관련 원저 1편의 Methods·보충자료·그림을 연결한다. 매주 여러 책의 완독을 요구하지 않는다.

읽기 순서: 15분 훑기 → 단계별 목적·입력·출력 설명 → 시약·조건의 근거 확인 → 대조군·실패 예측 → 실제 관측과 대조. 원리 10h는 교재 4h·SOP/매뉴얼 3h·설명/카드 3h를 출발점으로 조절한다. 통계·논문 시간과 중복 계산하지 않는다.

**직접 배우고 수행할 것.** 재검토 기준과 작업 흐름을 개발 자료에서 정하고 전문가와 검토한다. 실제 조건은 채택한 SOP와 지도에 따른다. 수행 전 준비·수행·QC·기록을 한 과정으로 학습한다. 지도·시료·장비가 없으면 관찰·공개 자료 분석으로 대체하고 실제 수행 여부를 따로 적는다.

**대조군·QC·실패 해석.** 분류 확률 보정과 길이 측정 불확실성을 혼동하지 않는다. 합격·재측정·제외 기준은 결과를 보기 전에 지도자와 정하고 근거를 남긴다. 이미 본 결과에 맞춰 기준을 정했다면 탐색 결정으로 기록한다.

**설계·통계·생물정보학 8h.** 확률 보정·측정 오차·재검토율의 차이를 설명하고 함께 보고할 지표를 정한다. 현재 주제에 맞는 MSMB의 지정 부분과 실제 원저를 이용해 개념·설계 검토 3h, 작은 계산·자료 해석 3h, 자신의 실험 적용 2h로 나눈다. 아래 코딩 시간에는 같은 공부를 다시 세지 않고 구현·검산 작업만 기록한다.

**필요한 AI·코딩과 검증.** calibration·기권·재검토 후보를 학습한다. 성능과 사람이 검토해야 하는 양을 함께 본다. 이번 주 6h는 개념 약 2h·작은 적용 3h·검증 1h다. 추가 수학은 해당 계산을 이해하는 데 필요한 만큼 보충한다. 코드를 AI에 맡겨도 변수·입력·출력·단위·분할·평가와 한 개 이상의 독립 검산을 설명한다. 새 모델 구조를 만드는 것은 필수 과제가 아니다.

**월~토 60시간.** 실험·주력 연구 22h, 원리 10h, 설계·통계·생물정보학 8h, AI 6h, 논문·연구 글쓰기·회의 6h, 논술 8h. 실제 장비·실험 일정에 따라 블록을 옮길 수 있다. 일요일에는 정규 과제를 배정하지 않는다.

**논술 3회.** 월 한양 · 목 서강 · 토 중앙. 분기 초점: 자료 해석·불확실성. 이번 주 훈련: **전체 논증의 일관성**. 매회 독립적으로 답할 수 있는 서술형 논제 하나를 선택하고 학교·연도·문항·공식 출처를 기록한다. 초고부터 퇴고까지 각 150분, 연구 문단 30분으로 합계 8h다. 실제 문제 파일을 열기 전에는 특정 연도·문항을 확보한 것으로 기록하지 않는다. [선택·첨삭·퇴고 방법](../docs/writing_practice.md)

연구 문단 과제: 이번 주 질문에 300~500자로 답한다. 관측 사실, 해석, 대안 설명, 다음 확인을 구분하고 실제로 얻지 않은 결과를 만들지 않는다. 인문논술에서 발견한 반복 오류 하나를 이 문단에서 다시 점검한다.

**기존 세 논문의 진행.** P3 독립 평가·오류 분석·재현 자료를 완성하고 실제 증거가 지지하는 주장으로 원고를 정리한다. P1은 음향 리뷰, P2는 음향 평가, P3는 조직 측정 검증이다. 기존 투고 목표는 자료·검증·지도 일정에 따른 잠정 목표다. 새 기법마다 논문을 추가하지 않는다. 심사 의견이 없으면 동료 모의 심사 또는 재현성 점검을 하며 실제 심사로 기록하지 않는다.

**직접 답할 네 가지.**

1. 이번 주 질문에 가정·근거·단위를 포함해 3분 설명한다.
2. 선택한 단계 하나를 생략하거나 조건이 달라진다면 무엇이 바뀔지 예측하고 검증할 관측을 제안한다. 실제 SOP 변경은 지도자와 결정한다.
3. 생물학적 설명 하나와 기술적 대안 설명 하나를 구별할 대조·비교를 설계한다.
4. 현재 병목에 AI가 필요한지, 단순 규칙·수동·통계로 충분한지 판단하고 검증 계획을 쓴다.
