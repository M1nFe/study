**초보자 ML 16주 상세 계획**

[시작 화면](README.md) · [자료와 링크](resources.md) · [학습 기록](learning-log.md)

주 8시간: 강의·읽기 2h + 직접 실습 4h + 설명·오류 수정·기록 2h. 아래는 매주 수행할 계획이며 이미 구현한 결과가 아니다. 자료는 지정한 주제만 선택한다. 전 강좌 완강과 이 계획의 과제를 동시에 요구하지 않는다. 연습 과제는 이 과정에서 만든 것이며 원 교재의 공식 문제 번호를 뜻하지 않는다.

**1주 · 변수·자료형·입출력.**

- 자료: CS50P Functions, Variables의 변수·숫자·문자열·입출력. 처음에는 실행과 값의 변화를 이해한다.
- 실습: 장바구니 합계와 단위 변환 계산기를 만든다. 문자열 입력을 숫자로 바꾸고, 변수 하나를 바꾼 결과를 실행 전에 적는다.
- 수학: 사칙연산, 비율, 단위. 분수·소수·백분율을 같은 값으로 나타낸다.
- 결과물: 작은 계산 노트북과 변수 5개의 뜻.
- 통과: `"3"`과 `3`의 차이, 변수 값을 바꿨을 때 결과가 바뀌는 이유를 설명한다. 그대로 따라 친 예제의 숫자를 바꿔도 수정할 수 있다.

**2주 · 조건문·반복문·함수.**

- 자료: CS50P Conditionals, Loops의 기초와 Functions의 인수·반환값. 중첩이 복잡한 과제는 다음으로 미룬다.
- 실습: 점수 목록의 합계·평균·기준 이상 개수를 계산한다. 같은 계산을 함수로 만들고 다른 목록을 넣는다.
- 수학: 비교 연산, 평균, 함수의 입력과 출력.
- 결과물: 재사용할 수 있는 함수 2개와 입력·출력 예 3쌍.
- 통과: 반복 횟수와 변수 변화를 손으로 따라가고 `print`와 `return`의 역할을 구분한다. 빈 목록 같은 예외 입력을 어떻게 처리할지 설명한다.

**3주 · 리스트·딕셔너리·CSV·오류 읽기.**

- 자료: CS50P Loops의 자료구조, Exceptions, Libraries의 import, File I/O의 텍스트·CSV 선택 부분. 해당 부분만 읽으며 전문 클래스 설계는 미룬다.
- 실습: 가상의 도서 대출 기록 10행을 만들고 파일로 저장·읽는다. 책별 대출 횟수와 빈 칸을 확인한다. 일부러 파일명·숫자 형식을 틀리게 해 오류를 읽는다.
- 수학: 개수, 빈도, 비율. 비어 있음과 숫자 0을 구분한다.
- 결과물: 가상 CSV와 읽기·집계 함수. 실제 사람의 개인정보를 사용할 필요는 없다.
- 통과: 에러의 마지막 줄과 관련 코드 위치를 찾고, 원인·수정·재확인을 자신의 말로 설명한다. 함수·리스트/딕셔너리 순회·CSV 읽기를 아직 혼자 못 하면 여기서 1~2주를 보충한다.

**4주 · NumPy·pandas와 첫 점검.**

- 자료: NumPy beginner guide의 배열·shape·인덱싱·집계; pandas introductory tutorials의 표 읽기·선택·요약. 전체 문서를 외우지 않는다.
- 실습: 3주차 CSV를 DataFrame으로 읽고 행·열 선택, 조건 필터, 결측 확인, 그룹별 요약을 수행한다. 작은 배열에서 `axis`를 바꾼 결과를 손계산과 대조한다.
- 수학: 벡터는 값의 목록, 행렬은 행·열의 표로 시작한다. 배열 크기와 각 축의 뜻을 적는다.
- 결과물: 원자료 행 수, 요약표, 결측 처리 판단을 담은 노트북.
- 통과: 예시를 닫고 새로운 작은 CSV를 읽어 질문 3개에 답한다. 못하면 1~4주를 더 연습하고 모델 학습은 미룬다.

**5주 · 데이터 탐색과 필요한 수학.**

- 자료: pandas introductory tutorials의 plotting·summary statistics; MLCC의 선수 수학 안내; 선택 ISLP의 Statistical Learning 개요.
- 실습: 가상 기록의 분포·그룹별 요약·두 숫자 변수의 산점도를 그린다. 극단값 하나를 넣어 평균과 중앙값이 달라지는 모습을 확인한다. 이후 프로젝트용 Wine 데이터는 아직 사용하지 않는다.
- 수학: 평균·중앙값을 계산하고 분산·표준편차를 값의 퍼짐으로 해석한다. 행렬의 행·열 의미를 복습한다. 확률은 8주 분류에서, 일차함수는 6주 회귀에서 배우며 내적과 증명은 선택 보충으로 둔다.
- 결과물: 제목·축·단위가 있는 그림 3개와 각 그림에서 알 수 있는 것·없는 것.
- 통과: 상관만으로 원인을 단정하지 않고, 한 행과 한 열이 무엇을 뜻하는지 설명한다.

**6주 · 첫 선형회귀와 손실.**

- 자료: MLCC Linear Regression의 모델·loss·gradient descent 직관. 선택 ISLP Linear Regression의 단순 회귀. 미분의 상세 증명은 보충 과제로 둔다.
- 실습: 알려진 직선에 잡음을 더한 학습용 데이터를 만든다. 먼저 학습용·평가용을 나눈 뒤 학습 자료에서 모델을 맞춘다. 가중치·절편을 손으로 바꾸고 작은 표의 오차를 계산한다.
- 수학: `예측 = 기울기 × 입력 + 절편`, 실제값과 예측값의 차이, 제곱·평균. 파라미터 변경과 손실 변화의 방향을 이해한다.
- 결과물: 데이터·직선·잔차 그림, 작은 MSE 손계산. 합성 자료의 점수를 실제 문제 성능으로 보고하지 않는다.
- 통과: 학습한다는 것이 무엇을 정하는 일인지 설명하고, 학습에 쓴 자료를 그대로 평가하는 것의 한계를 말한다.

**7주 · 분할·기준 모델·회귀 평가.**

- 자료: scikit-learn MOOC의 평가 관련 선택 부분, scikit-learn common pitfalls의 누수; 선택 ISLP의 학습·시험 오차 부분.
- 실습: 단순히 학습 자료의 평균을 예측하는 DummyRegressor와 선형회귀를 같은 분할에서 비교한다. 입력에 쓸 수 없는 정답 관련 열을 일부러 넣고 왜 잘못됐는지 설명한다.
- 수학: MAE와 RMSE를 작은 숫자로 계산하고 원래 값의 단위를 확인한다.
- 결과물: 기준 모델과 회귀의 학습·평가 지표 표, 변수 사용 시점 목록.
- 통과: 학습 자료, 모델 선택에 쓸 검증 자료, 마지막 시험 자료의 목적을 구분한다. 반복해서 본 평가 자료를 새로운 최종 시험이라고 부르지 않는다.

**8주 · 분류·로지스틱 회귀·지표.**

- 자료: MLCC Logistic Regression·Classification 중 확률·threshold·confusion matrix 부분; scikit-learn MOOC의 분류 예제.
- 실습: 작은 이진 예제에서 threshold를 바꿔 손으로 예측한다. 이어 학습용 Iris 분류에서 DummyClassifier와 로지스틱 회귀를 비교한다. 수치 스케일 변환은 학습 자료에 맞춘 간단한 Pipeline 예제를 사용하고 9주에 구조를 풀어본다.
- 수학: 빈도·비율로 확률을 시작하고 TP·FP·FN·TN, accuracy·precision·recall을 계산한다. 다중 분류에서는 클래스별 결과와 macro 평균을 구분한다. 3×3 혼동행렬을 행·열의 뜻부터 읽고 클래스마다 계산한 F1의 단순 평균이 macro-F1임을 확인한다.
- 결과물: confusion matrix, 지표의 의미, 틀린 예 최대 3개. 오류가 없으면 관찰된 오류 0개와 작은 평가 표본의 한계를 기록한다.
- 통과: 회귀와 분류, 확률과 최종 라벨을 구분한다. “정확도만 높으면 좋은 모델인가”에 클래스 구성과 오류 비용을 들어 답한다. 4~8주 핵심 개념을 5분 설명한다.

**9주 · 결측·범주형·스케일·Pipeline.**

- 자료: scikit-learn MOOC의 numerical/categorical preprocessing; common pitfalls의 전처리 누수; pandas 결측 예제.
- 실습: 작은 학습용 표에 숫자·범주형·결측을 넣고 imputation·encoding·scaling과 모델을 연결한다. 처음부터 제공된 짧은 예제를 분해해 각 단계의 입력·출력을 확인한다.
- 수학: 표준화의 평균·표준편차를 작은 표에서 계산한다.
- 결과물: 전처리→모델 흐름도와 Pipeline. 시험 자료의 평균으로 표준화한 잘못된 예와 비교한다.
- 통과: `fit`과 `transform`을 구분하고, 전처리도 학습 자료에서 배워야 하는 이유를 설명한다.

**10주 · 교차검증·과적합·규제.**

- 자료: scikit-learn MOOC의 cross-validation·overfitting·linear models 선택 부분; 선택 ISLP Resampling Methods·regularization 관련 소절.
- 실습: 마지막 평가 자료는 따로 두고 개발 자료에서만 교차검증한다. 규제 강도 후보를 소수로 정해 같은 fold에서 비교한다. 전처리도 fold 안에서 적합되게 Pipeline을 사용한다.
- 수학: fold별 점수의 평균·변동. 규제가 모델의 자유도를 제한한다는 직관을 작은 비교로 확인한다.
- 결과물: 후보·fold·평가 기준·선택 이유. 무작정 후보 수를 늘리지 않는다.
- 통과: 교차검증 점수의 변동을 모집단 신뢰구간으로 단정하지 않는다. 더 복잡한 모델이 항상 새 자료에 유리하지 않은 이유를 설명한다.

**11주 · 결정트리·랜덤포레스트.**

- 자료: scikit-learn MOOC의 decision trees·ensemble 소개; 선택 ISLP Tree-Based Methods의 해당 소절.
- 실습: 작은 트리의 분기 조건을 따라 예측을 손으로 확인한다. 깊이가 다른 트리와 랜덤포레스트를 같은 개발 분할에서 비교한다. 이번 주 필수 모델은 이 둘까지다.
- 수학: 분할 전후 클래스 구성, 여러 예측을 모으는 직관. impurity 공식의 상세 유도는 선택이다.
- 결과물: 트리 그림, 학습·검증 성능 비교, 잘못 분류한 사례.
- 통과: 트리의 예측 하나를 설명하고, 랜덤포레스트가 언제든 선형 모델을 이긴다고 주장하지 않는다.

**12주 · 비지도학습 맛보기 또는 보충 주간.**

- 자료: 선택 ISLP Unsupervised Learning의 clustering·PCA 직관, scikit-learn MOOC의 관련 자료가 있는 범위 또는 공식 사용자 가이드.
- 실습: 작은 합성 점에서 K-means가 거리와 스케일에 영향을 받는지 확인한다. 여력이 있으면 PCA 2차원 그림을 보고 차원 축소의 뜻을 설명한다.
- 수학: 두 점 사이 거리·평균, 정보를 요약하는 방향. 고유값 분해의 증명은 현재 필수가 아니다.
- 결과물: 정답 라벨 없이 찾은 군집 그림과 해석의 한계.
- 통과: 군집 번호를 실제 정답·원인으로 단정하지 않는다. 9~11주가 어렵다면 K-means/PCA 대신 Pipeline·교차검증을 보충한다. 비지도학습의 정의를 설명하면 이번 맛보기의 최소 목표를 충족한다.

**13주 · 오류 분석과 비교의 신뢰성.**

- 자료: scikit-learn MOOC의 evaluation 선택 부분; common pitfalls. feature importance는 필요할 때 공식 문서의 해석 주의점을 읽는다.
- 실습: 정답이 틀린 행, 중복된 행, 평가에 섞이면 안 되는 그룹이 있는 모의 자료를 점검한다. 개발 자료에서 모델이 틀린 사례를 비교하고 고칠 문제를 한 가지 정한다.
- 수학: 소수 표본에서 점수가 흔들리는 이유, 클래스별 오류의 비율.
- 결과물: “좋은 점수인데 잘못된 분석” 사례 2개와 수정안. 중요도가 높다는 것을 인과관계로 해석하지 않는다.
- 통과: 자료 없이 문제→데이터→분할→전처리→기준 모델→검증→한계의 흐름을 설명한다. 못하면 최종 프로젝트 전에 보충한다.

**14주 · 첫 프로젝트 설계와 데이터 이해.**

- 자료: 공식 Wine 데이터 설명, 지금까지의 노트, 아래 프로젝트 명세.
- 실습: 처음 사용하는 Wine 데이터의 예측 대상·특징을 확인한다. 고정한 분할 규칙으로 최종 시험 자료를 먼저 분리하고 저장한다. 개발 자료만 탐색한다. 간단한 Git 사용으로 변경 기록을 남기거나, 익숙하지 않으면 우선 날짜별 버전을 보존한다.
- 판단: 어떤 지표로 어떤 기준 모델과 비교할지, 어떤 결과까지 주장할 수 있는지 미리 적는다.
- 결과물: 계획서 1쪽, 데이터 사전, 분할 ID·seed, 개발 자료 요약.
- 통과: 예측 대상이 특징에 섞이지 않았고 프로젝트 규칙을 실행 전에 설명한다. 이 자료의 실습 결과를 현장 배포 성능으로 확대하지 않는다.

**15주 · 기준 모델·비교·최종 평가.**

- 자료: 필요한 scikit-learn API·전처리·평가 문서만 찾아본다. 새 강좌를 추가하지 않는다.
- 실습: DummyClassifier, 전처리를 포함한 로지스틱 회귀, 랜덤포레스트를 같은 개발 교차검증 분할에서 비교한다. 선택 기준과 설정을 고정한 뒤 선택한 모델(전처리가 있으면 Pipeline 포함)과 기준 모델을 각각 개발 자료 전체에 다시 `fit`하고 보관한 시험 자료에서 평가한다. 마지막 fold의 모델을 그대로 최종 모델로 사용하지 않는다.
- 판단: macro-F1을 주지표로 정했다면 계속 사용하고 클래스별 성능·confusion matrix도 본다. 좋은 숫자가 나올 때까지 split·seed를 바꾸지 않는다.
- 결과물: 개발 비교표, 최종 결과, 관찰된 실패 사례와 제한. 오류가 없으면 0개로 기록하고 사례를 만들어내지 않는다.
- 통과: 최종 시험 결과를 확인한 뒤 다시 튜닝하지 않는다. 불가피하게 방법을 바꾸면 해당 평가가 탐색으로 바뀌었음을 기록한다.

**16주 · 재실행·보고서·5분 설명.**

- 자료: 본인 노트와 필요한 공식 문서. 새로운 알고리즘 학습은 다음 과정으로 넘긴다.
- 실습: 실행 상태를 초기화하고 노트북을 처음부터 끝까지 돌린다. 파일 위치·라이브러리 버전·분할·수동 작업을 기록한다. 보고서 2쪽과 5분 설명을 준비한다.
- 결과물: 실행 가능한 노트북, README, 실제 결과표, 관찰된 오류·평가의 한계, 다음 질문 3개.
- 통과: 코드 중 5개 핵심 부분을 골라 입력·출력·이유를 설명하고, 숫자나 조건을 바꾼 작은 문제를 혼자 해결한다. 높은 점수를 통과 조건으로 삼지 않는다.

**최종 프로젝트 명세.** 기본 과제는 scikit-learn의 Wine 데이터로 클래스 예측의 전체 흐름을 익히는 것이다. 데이터의 실제 뜻과 원 출처는 [공식 설명](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html)을 읽고 기록한다. 소규모 교육 자료이며 실제 배포·인과 추론을 검증하는 프로젝트가 아니다.

1. 예측할 y, 입력 X, 한 행의 뜻, 특징의 단위를 적는다.
2. 예를 들어 층화한 80:20 분할로 시험 자료를 먼저 보관한다. 클래스·표본 수가 분할과 fold 수에 적합한지 확인한다. 약 20%라는 비율 자체가 타당성의 보장은 아니다.
3. 나머지 개발 자료에서 동일한 층화 5-fold를 사용해 소수 후보를 비교한다. 작은 자료의 fold 점수 평균·변동은 개발 비교용으로 보고한다.
4. 전처리는 Pipeline 안에서 각 학습 fold에 적합한다. 열 선택·튜닝을 포함한 결정에 시험 결과를 사용하지 않는다.
5. 선택한 모델의 설정과 Dummy 기준을 고정하고 각각 개발 자료 전체에 다시 적합한다. 전처리도 함께 다시 적합한 후 시험 성능과 오류를 기록한다. 성능이 기대보다 낮아도 원인을 분석하고 그대로 보고할 수 있다. 오류가 관찰되지 않았어도 작은 표본에서 확인한 범위와 한계를 남긴다.
6. 다른 사람이 재실행할 수 있게 버전·실행 순서·seed·한계를 남긴다. 완성 예제의 결과를 자신의 실행 결과로 복사하지 않는다.
