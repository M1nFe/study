**완전 초보 친구를 위한 머신러닝 첫 16주**

코딩 경험이 거의 없고 머신러닝을 처음 공부하는 사람을 위한 과정이다. 주 8시간, 총 128시간을 기준으로 한다. 친구의 실제 수학·코딩 경험과 목적은 아직 확인되지 않았으므로 첫 주에 기록하고 조정한다. 이 계획은 저장소 주인의 주 60시간 연구 과정과 별개다.

**목표.** 작은 표 데이터를 읽고 정리해 모델을 학습시키며, 처음 보는 자료에서 평가하고, 결과와 한계를 자신의 말로 설명하는 첫 프로젝트를 완성한다. 모든 ML 기법을 익히거나 취업 준비를 끝내는 과정은 아니다.

**16주 흐름.**

| 기간 | 배우는 것 | 확인할 결과 |
|---|---|---|
| 1~4주 | Python, NumPy, pandas | 작은 CSV를 읽고 조건별 요약을 직접 작성 |
| 5~8주 | 데이터 탐색, 필요한 수학, 회귀·분류·평가 | 단순 기준과 모델을 비교하고 오차 설명 |
| 9~13주 | 전처리, 교차검증, 규제, 트리, 오류 분석 | 데이터 누수 없이 방법을 비교 |
| 14~16주 | 새로운 데이터로 첫 프로젝트 | 실행 가능한 노트북·보고서·5분 설명 |

**주 8시간의 사용법.** 주 4회, 회당 2시간을 권한다. 강의·문서 2시간, 직접 실습 4시간, 설명·오류 수정·기록 2시간이다.

| 회차 | 2시간 동안 할 일 |
|---|---|
| 1회 | 개념 60분 → 작은 예제 45분 → 이해한 내용 15분 기록 |
| 2회 | 문서 60분 → 예제를 바꿔 실행 60분 |
| 3회 | 처음부터 작성·문제 해결 90분 → 오류와 수정 이유 30분 |
| 4회 | 조건을 바꾼 문제 45분 → 자료 없이 설명·복습·주간 기록 75분 |

코드가 실행되는 데 그치지 않고 “입력은 무엇이며, 이 줄이 무엇을 바꾸고, 출력은 왜 이렇게 나왔는가”를 설명한다. 한 번에 완성 코드를 외우기보다 작은 숫자·조건을 바꾸며 확인한다.

**첫날 2시간.**

1. 15분: [Colab](https://colab.research.google.com/) 또는 이미 쓰는 Python 환경에서 새 노트북을 만들고 `print(2 + 3)`을 실행한다. 이 과정의 작은 예제는 CPU로 진행한다.
2. 45분: CS50P의 Functions, Variables에서 변수·숫자·문자열·출력 부분을 보고 직접 입력한다. 전체 강의를 이날 끝낼 필요는 없다.
3. 45분: 가격 1,200원인 물건 3개와 800원인 물건 2개의 합계를 변수로 계산한다. 수량·가격을 바꾸고 실행 전 결과를 예상한다. 문자열과 숫자를 잘못 더했을 때의 오류도 확인한다.
4. 15분: 새로 배운 것 3개, 막힌 것 1개, 다음에 바꿔볼 조건 1개를 적는다. 노트북을 저장하고 다시 열어본다.

Colab은 설치 없이 사용할 수 있는 노트북 환경이다. 실습은 무료 기본 환경을 출발점으로 하며 유료 GPU를 전제하지 않는다. [공식 안내](https://research.google.com/colaboratory/faq.html)

**속도 조절.** 처음부터 16주를 마감일로 삼지 않는다. 4·8·13·16주의 통과 기준으로 속도를 정한다. 8시간 안에 과제를 끝내지 못하면 다음 주로 나누고 20~24주로 늘려도 된다. 주 4시간이라면 각 주를 두 주로 나누어 약 32주로 진행한다.

이미 Python을 안다면 조건·반복·함수로 작은 표를 처리하고, CSV를 읽어 결측·행 수·평균을 설명하는 과제를 도움 없이 해본다. 통과한 부분만 생략한다. 본인의 학습 시간이 늘었다고 선수 개념을 이해한 것으로 간주하지 않는다.

**AI 활용.** 먼저 15~20분 시도한 뒤 모르는 개념·오류 메시지·작은 힌트를 묻는다. 답을 받으면 한 조건을 바꿔 혼자 다시 풀고 도움받은 부분을 기록한다. 처음에는 자동완성한 긴 코드를 그대로 제출하지 않는다.

```text
나는 Python과 머신러닝 초보자야.
현재 목표, 내 코드, 예상 결과, 실제 오류를 줄게.
완성 코드를 바로 주지 말고 가장 작은 힌트 하나를 먼저 줘.
내가 수정하면 각 변수의 의미와 출력이 왜 그렇게 되는지 질문해줘.
마지막에는 같은 개념을 사용하는 숫자·조건이 다른 문제를 하나 내줘.
```
