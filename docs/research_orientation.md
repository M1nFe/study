**공개 음향 분석의 검증에서 음성·행동 관찰 연구로**

2026-10-08 개정. 석사 2학기, 주 60시간을 기준으로 한다. 현재 실행 기준은 [8주 집중 과정](../curriculum.md)과 [연구 로드맵](roadmap.md)이다. 2026-10-01의 조직·분자·세포 실험 중심 52주 과정은 장기 기초로 보존하며, 현재 음향 분석을 시작하기 위한 선행 수료 조건으로 두지 않는다.

**지금 완성할 연구.** SoundWel 공개데이터에서 음향 특징과 평가 방법의 타당성을 검증하고, 그 결과를 음성·행동을 함께 관찰하는 후속 수집 설계로 연결한다. 공개자료 분석의 방법·결과·한계를 하나의 검토 가능한 원고로 만드는 일을 우선한다. 관련 학습과 집필은 분석 첫 주부터 병행한다.

**연구 정체성.** 생물학적 질문을 세우고, 그것을 관측할 실험을 설계하며, 측정의 오류와 한계를 이해하고, 필요한 분석·AI를 선택해 검증하는 연구자를 목표로 한다. 새 신경망 구조를 발표하는 일을 현재 필수 목표로 삼지 않는다. 기존 방법으로도 문제 설정·측정·데이터·검증에 실질적인 새 기여가 있는지를 판단한다. 단순한 모델 비교나 공개데이터 재분석만으로 논문 가치가 확보되지는 않는다.

**Lee 등의 2024년 논문에서 가져올 질문.** [연결 문서](lee2024_bridge.md)에 원문 근거와 적용 범위를 정리한다. 이유 스트레스 회복탄력성과 이후 놀람 반응의 관계를 다룬 연구를, 자극에 대한 반응과 이후 회복을 어떤 관측으로 구분할지 생각하는 출발점으로 삼는다. 관련이 보고되지 않은 결과도 보존하며, 어떤 하나의 음향 점수가 회복탄력성을 대신한다고 가정하지 않는다.

| 연구 단계 | 직접 확인할 수 있는 것 | 아직 필요한 별도 증거 |
|---|---|---|
| SoundWel 공개자료 | 맥락별 발성 특징, 식별 가능한 그룹을 분리했을 때의 분류·추론 안정성, 결측·분할 민감도 | 개체별 회복탄력성 정답, 연속 관찰의 기저 상태·반응·회복 시간, 자연 발성률 |
| 현재 한 돈방·30두 현장 파일럿 | 오디오·영상 동기화, 행동 주석 가능성, 관찰 가능한 집단 신호, 기존 사양 단계 주변의 시계열 | 독립 돈방·코호트의 반복, 신뢰할 수 있는 개인 발성자 식별, 회복 지표의 외부 타당성 |
| 후속 검증 연구 | 파일럿으로 정의한 지표의 반복성·변화·다른 행동 또는 생산성 지표와의 관계 | 설계가 허용하는 범위를 넘어선 인과 효과·개체 진단·다른 농장 일반화 |

SoundWel의 잘라 놓은 발성으로 자연 발성률·자극 후 잠복기·회복 시간을 계산하지 않는다. 공개자료의 `Surprise` 맥락을 Lee 논문의 표준화된 놀람시험과 동일하게 다루지 않는다. 이유자돈의 결과를 육성·비육돈 군사육에 그대로 옮기지 않고, 연령·환경·자극·관측 단위의 차이를 후속 설계에 기록한다. 현장 파일럿은 현재 사양시험을 관찰하는 범위로 준비한다. 놀람 유발이나 생리 시료 채취는 이 과정의 필수 요구가 아니며, ATTD는 현재 계획에서 제외한다.

**주 60시간의 현재 배분.** 8주 동안 아래 배분을 사용한다. 기존 52주 과정의 시간표를 추가로 더하지 않는다.

| 활동 | 시간 | 남길 증거 |
|---|---:|---|
| SoundWel 데이터 감사·코딩·분석·검증 | 24h | 데이터 계보, 분할표, 실행 설정·로그, 결과와 실패 기록 |
| 관련 생물학·실험 설계·통계 | 8h | 독립 단위, 라벨의 의미, 비교식, 효과와 불확실성 |
| 논문 읽기·연구 글쓰기·회의 | 10h | 원문 근거표, Methods·그림·원고, 검토 기록 |
| 기존 연구실 업무·필수 실험 숙련·현장 준비 | 10h | 수행 기록, 동기화·관찰·주석·보관 SOP |
| 인문논술·첨삭·퇴고 | 8h | 월·목·토 3개 초고와 수정본, 연구 문단 1개 |
| 합계 | 60h | 공부·연구·글쓰기를 모두 포함 |

같은 시간을 두 항목에 중복해서 넣지 않는다. 장시간 실험의 대기 시간을 전부 집중 학습으로 세지 않는다. 강의·조교·필수 실험이 60시간에 포함되면 먼저 반영하고 주차를 늘리거나 범위를 줄인다. 논술은 기존 주 3회와 8시간을 유지한다. 새 모델이나 추가 실험은 남는 시간에 자동으로 얹는 과제가 아니라, 기존 작업과 우선순위를 비교해 선택한다.

**학습의 순서를 분석의 필요에 맞춘다.** 첫 주에는 라벨·독립 단위·결측을, 둘째 주에는 그룹 분할과 기준 모델을 배운다. 효과크기·다중검정·계층 자료는 특징을 해석하는 주에 학습한다. 사전학습 모델은 단순 기준 모델과 유효한 평가가 준비된 뒤에 적용한다. 대형 모델 학습이나 새로운 attention 구조보다 지금의 비교를 왜 믿을 수 있는지 설명하는 능력을 먼저 확보한다.

**장기 실험 숙련의 우선순위.** 아래는 보존한 52주 기초 과정의 기준이다. 현재 연구에 직접 필요한 부분을 연구실 지도와 실제 일정 안에서 선택한다. 주력은 조직·현미경·형태 측정과 RNA·RT-qPCR이다. 단백질 분석과 세포배양은 질문을 검증하는 데 필요한 범위로 배운다. 실험 종류를 많이 경험한 것과 독립적으로 수행할 수 있는 것은 구분한다. 첫해에 모든 기법을 같은 깊이로 숙련하려 하지 않는다.

| 단계 | 능력의 증거 | 확인 방법 |
|---|---|---|
| L1 원리 이해 | 단계의 목적·입력·출력·가정·대조군을 설명 | 프로토콜을 덮고 지도자에게 설명 |
| L2 지도하 수행 | SOP를 따라 수행하고 이탈·관측을 기록 | 지도자 관찰과 원자료 검토 |
| L3 독립 수행 | 서로 다른 수행일의 결과를 합의된 QC 기준으로 재현 | 사전에 정한 반복 수·허용 범위로 확인 |
| L4 오류 진단 | 실패 원인을 구별할 관측과 다음 확인을 제안 | 실제 실패 사례를 근거로 방어 |

주차를 마쳤다는 이유로 L3가 되지 않는다. 기초 과정의 12주에는 조직 분석, 20주에는 RNA·qPCR 수준을 점검한다. 이 번호는 현재 음향 8주 과정의 번호와 다르다. 단백질·세포배양은 초기 L1~L2를 목표로 시작하며 연구에 채택한 기법만 L3까지 반복한다. 직접 할 수 없는 주에는 관찰·공개 예제로 공부하고 실제 수행으로 기록하지 않는다.

**프로토콜을 읽는 여덟 질문.** 이 질문은 특정 장비·시약의 실행 SOP를 대체하지 않는다. 실제 조건은 연구실에서 채택한 SOP, 사용 제품의 현행 매뉴얼, 지도자의 설명과 대조한다.

1. 이 실험이 직접 측정하는 것은 무엇이며, 알고 싶은 생물학적 상태와 얼마나 떨어져 있는가?
2. 각 단계는 시료를 어떤 상태에서 어떤 상태로 바꾸는가?
3. 시약·시간·온도·순서·농도가 중요한 이유는 무엇인가? 근거와 추측을 구분했는가?
4. 단계를 생략하거나 조건이 달라지면 어떤 관측이 바뀔 것으로 예상하는가?
5. 양성·음성·공정 대조군은 각각 어떤 대안 설명을 검사하는가?
6. 생물학적 차이와 기술적 차이는 어디에서 발생하며 어떻게 분리할 것인가?
7. 성공·재측정·제외를 어떤 기준으로 판단할 것인가? 결과 전에 정했는가?
8. 이 과정의 반복 작업이나 측정 오차 중 소프트웨어·AI로 개선할 부분은 무엇인가?

이 접근은 동물 연구의 설계·보고를 점검하는 [ARRIVE 2.0](https://arriveguidelines.org/arrive-guidelines), RT-qPCR의 표본·분석·보고를 점검하는 [MIQE 2.0](https://pubmed.ncbi.nlm.nih.gov/40272429/)와 함께 사용한다. 두 지침은 서로 다른 범위의 자료이며 실험 원리 교재나 개별 SOP를 대신하지 않는다.

**실험에서 AI 연구 질문으로 연결하는 예.** 아래는 제안이며 이미 구축한 모델이나 입증된 성능이 아니다. 모든 과제에서 먼저 수동·규칙·단순 통계 기준 방법을 둔다.

| 실험의 병목 | 가능한 도구·모델 | 필요한 정답·검증 | 먼저 판단할 점 |
|---|---|---|---|
| 조직 이미지의 초점·주름·절단 상태 검토 | 규칙 기반 QC, 분류기, 사전학습 특징 | 전문가의 QC 판정, 동물·염색 배치를 분리한 평가 | 정상적인 생물학적 변이를 불량으로 버리지 않는가 |
| 융털·음와 경계와 길이 측정 | U-Net 계열 분할과 기하 측정 | 전문가 길이, µm 교정, 일치도와 수정 시간 | 픽셀 점수 개선이 실제 측정 개선으로 이어지는가 |
| 세포 수·분포의 반복 계수 | 검증된 세포 분할·검출 모델 | 독립 시야의 수동 계수, 밀도·배치별 오류 | 겹친 세포와 잔해가 어떤 편향을 만드는가 |
| qPCR 판별·QC 확인 | 기존 분석 소프트웨어, 규칙 검사; 자료가 충분하면 이상 탐지 | 원 곡선, 대조군, 전문가 판정, 다른 run 검증 | AI가 없어도 해결되는가; 이상치를 임의 삭제하지 않는가 |
| 음향의 반복 검토 | 음향 특징+선형 모델, 동결 표현 | 정의된 맥락 라벨, 세션·그룹 평가 | 예측 라벨을 감정·질병의 직접 측정으로 확대하지 않는가 |
| 프로토콜·시료 기록 정리 | 검증 규칙, 검색, 출처를 붙인 LLM 초안 | 원 SOP 대조, 누락·환각 검사 | 실제 조건과 결과를 생성 모델이 만들어내지 않는가 |

**AI에서 직접 책임질 최소 역량.** 데이터의 행·열·단위, 예측 시점, 정답 정의, 독립 표본, 학습/검증/시험 분리, 누수, 과적합, 불확실성, 손실과 평가 지표의 차이를 설명한다. 선형/로지스틱 회귀·트리·사전학습·분할의 적용 조건을 이해한다. 작은 입력에 대한 예상 결과와 실제 코드를 대조한다. 현재 과정에서는 개념 학습을 관련 생물학·통계 8시간에, 구현과 검증을 분석 24시간에 포함한다. 별도 AI 강의 시간을 추가하지 않는다. 필요한 코드를 작은 예제로 설명한 뒤 실제 분석에 적용한다.

고급 optimizer의 상세 유도, 대형 모델 처음부터 학습, 새 attention 구조의 설계는 현재 선택 과제다. [기존 ML·DL 심화 문서](ml_dl_depth_plan.md)는 필요할 때 찾아보는 심화 자료로 보존한다. 코드를 AI에 맡겨도 연구 질문·대조군·분할·평가·해석은 연구자가 결정한다.

**논문 목표와 실험 학습을 연결하는 방식.** 현재 우선 원고는 SoundWel 분석 방법 검증이다. 기존 음향 리뷰는 필요한 근거표와 서론·고찰 작성에 연결하고, 조직 측정 연구는 확보된 자료·협력·필수 연구실 일정 안에서 유지한다. 세 원고를 같은 속도로 동시에 밀어붙이지 않는다. 4주차에는 유효한 비교와 기존 연구 대비 새 기여가 있는지 검토하고, 부족하면 범위를 줄이거나 자료 확보를 먼저 한다. 7주차에 전체 초고와 재현 확인을, 8주차에는 공동저자 검토를 반영한 투고 준비 상태를 목표로 한다. 실제 결과와 검토가 부족하면 일정은 연장한다.

새로 배우는 기법마다 별도 논문을 추가하지 않는다. RNA·단백질·세포배양은 연구 질문과 시료 연결이 있을 때만 논문에 포함한다. 서로 다른 동물에서 얻은 조직과 공개 전사체를 임의로 짝짓지 않는다. 음향 분석에서 확인한 통계적 관련성을 개체의 감정·회복탄력성 진단으로 확대하지 않는다. 한 돈방의 반복 관찰을 여러 독립 처리 반복처럼 계산하지 않는다.

**논문을 읽을 때의 초점.** 결과 그림 하나를 고른 뒤, 그 그림이 생기기까지 표본→처리→측정→QC→정규화→통계의 경로를 역추적한다. Methods의 각 단계에 위 여덟 질문을 적용하고, 결론을 설명할 다른 원인 하나와 이를 구별할 대조군을 제안한다. 이 과정의 핵심을 300~500자로 쓰는 연습을 인문논술과 연결한다.
