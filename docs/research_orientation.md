**실험을 이해하고 AI를 활용하는 축산 연구자로의 방향 조정**

2026-10-01 개정. 석사 2학기, 주 60시간. 사용자는 교수님의 도움으로 대부분의 실험을 배울 수 있다고 밝혔다. 실제 장비·시료·일정·지도 담당자는 첫 주에 확인한다. 현재의 실행 기준은 [52주 계획](../curriculum.md)이다.

**연구 정체성.** 생물학적 질문을 세우고, 그것을 관측할 실험을 설계하며, 측정의 오류와 한계를 이해하고, 필요한 분석·AI를 선택해 검증하는 연구자를 목표로 한다. 새 신경망 구조를 발표하는 일을 올해 필수 목표로 삼지 않는다. AI를 이용한 측정 도구나 예측 모델의 개발은 이 역할에 포함될 수 있다. 새로운 알고리즘이 없더라도 문제 설정·측정·데이터·독립 검증에 실질적인 기여가 있는지를 평가한다. 특정 기여만으로 논문 게재를 보장할 수는 없다.

기존 계획은 사용자의 ML 기초 보강 요청을 크게 반영해 처음 16주에 주 20시간을 배정했다. 현재 확인된 연구 지향에는 그 비중이 과하다. 수학·AI의 학습 목표를 연구 판단에 필요한 수준으로 좁히고, 프로토콜의 원리·직접 수행·대조군·오류 진단에 시간을 옮긴다.

**주 60시간의 기본 배분.** 같은 시간을 두 항목에 중복해서 넣지 않는다.

| 활동 | 시간 | 남길 증거 |
|---|---:|---|
| Wetlab·주력 연구 수행·측정·QC | 22h | 실험 기록, 원자료, 실패·재측정의 근거 |
| 생물학·프로토콜 원리 | 10h | 단계별 목적·작용·실패 조건을 설명한 카드 |
| 실험 설계·통계·생물정보학 | 8h | 독립 단위, 비교식, 대조군, 효과와 불확실성 |
| 필요한 AI·코딩·분석 검증 | 6h | 단순 기준 방법과 비교한 작은 검증 |
| 논문 읽기·연구 글쓰기·회의 | 6h | Methods 대조, 근거 있는 주장, 원고·그림 |
| 인문논술·첨삭·퇴고 | 8h | 주 3개 초고와 수정본, 연구 문단 1개 |
| 합계 | 60h | 공부·연구·글쓰기를 모두 포함 |

장시간 실험의 대기 시간을 전부 집중 학습 시간으로 세지 않는다. 배양·장비·지도 일정에 맞춰 요일 블록을 이동하되 합계를 유지한다. 강의·조교 업무가 60시간에 포함되면 그 시간을 먼저 차감한다. 투고 집중 주간에는 사전에 다른 항목에서 시간을 옮기고, 연구 시간 위에 논술 시간을 추가하지 않는다.

**실험 숙련의 우선순위.** 주력은 조직·현미경·형태 측정과 RNA·RT-qPCR이다. 단백질 분석과 세포배양은 질문을 검증하는 데 필요한 범위로 배운다. 실험 종류를 많이 경험한 것과 독립적으로 수행할 수 있는 것은 구분한다. 첫해에 모든 기법을 같은 깊이로 숙련하려 하지 않는다.

| 단계 | 능력의 증거 | 확인 방법 |
|---|---|---|
| L1 원리 이해 | 단계의 목적·입력·출력·가정·대조군을 설명 | 프로토콜을 덮고 지도자에게 설명 |
| L2 지도하 수행 | SOP를 따라 수행하고 이탈·관측을 기록 | 지도자 관찰과 원자료 검토 |
| L3 독립 수행 | 서로 다른 수행일의 결과를 합의된 QC 기준으로 재현 | 사전에 정한 반복 수·허용 범위로 확인 |
| L4 오류 진단 | 실패 원인을 구별할 관측과 다음 확인을 제안 | 실제 실패 사례를 근거로 방어 |

주차를 마쳤다는 이유로 L3가 되지 않는다. 12주에는 조직 분석의 수준을, 20주에는 RNA·qPCR의 수준을 점검한다. 단백질·세포배양은 초기 L1~L2를 목표로 시작하며 연구에 채택한 기법만 L3까지 반복한다. 직접 할 수 없는 주에는 관찰·공개 예제로 공부하고 실제 수행으로 기록하지 않는다.

**프로토콜을 읽는 여덟 질문.** 이 질문은 특정 장비·시약의 실행 SOP를 대체하지 않는다. 실제 조건은 연구실에서 채택한 SOP, 사용 제품의 현행 매뉴얼, 지도자의 설명과 대조한다.

1. 이 실험이 직접 측정하는 것은 무엇이며, 알고 싶은 생물학적 상태와 얼마나 떨어져 있는가?
2. 각 단계는 시료를 어떤 상태에서 어떤 상태로 바꾸는가?
3. 시약·시간·온도·순서·농도가 중요한 이유는 무엇인가? 근거와 추측을 구분했는가?
4. 단계를 생략하거나 조건이 달라지면 어떤 관측이 바뀔 것으로 예상하는가?
5. 양성·음성·공정 대조군은 각각 어떤 대안 설명을 검사하는가?
6. 생물학적 차이와 기술적 차이는 어디에서 발생하며 어떻게 분리할 것인가?
7. 성공·재측정·제외를 어떤 기준으로 판단할 것인가? 결과 전에 정했는가?
8. 이 과정의 반복 작업이나 측정 오차 중 소프트웨어·AI로 개선할 부분은 무엇인가?

이 접근은 동물 연구의 설계·보고를 점검하는 [ARRIVE 2.0](https://arriveguidelines.org/arrive-guidelines), RT-qPCR의 표본·분석·보고를 점검하는 [MIQE 2.0](https://pubmed.ncbi.nlm.nih.gov/40272429/)와 함께 사용한다. 두 지침은 서로 다른 범위의 자료이며 실험 원리 교재나 개별 SOP를 대신하지 않는다.

**실험에서 AI 연구 질문으로 연결하는 예.** 아래는 제안이며 이미 구축한 모델이나 입증된 성능이 아니다. 모든 과제에서 먼저 수동·규칙·단순 통계 기준 방법을 둔다.

| 실험의 병목 | 가능한 도구·모델 | 필요한 정답·검증 | 먼저 판단할 점 |
|---|---|---|---|
| 조직 이미지의 초점·주름·절단 상태 검토 | 규칙 기반 QC, 분류기, 사전학습 특징 | 전문가의 QC 판정, 동물·염색 배치를 분리한 평가 | 정상적인 생물학적 변이를 불량으로 버리지 않는가 |
| 융털·음와 경계와 길이 측정 | U-Net 계열 분할과 기하 측정 | 전문가 길이, µm 교정, 일치도와 수정 시간 | 픽셀 점수 개선이 실제 측정 개선으로 이어지는가 |
| 세포 수·분포의 반복 계수 | 검증된 세포 분할·검출 모델 | 독립 시야의 수동 계수, 밀도·배치별 오류 | 겹친 세포와 잔해가 어떤 편향을 만드는가 |
| qPCR 판별·QC 확인 | 기존 분석 소프트웨어, 규칙 검사; 자료가 충분하면 이상 탐지 | 원 곡선, 대조군, 전문가 판정, 다른 run 검증 | AI가 없어도 해결되는가; 이상치를 임의 삭제하지 않는가 |
| 음향의 반복 검토 | 음향 특징+선형 모델, 동결 표현 | 정의된 맥락 라벨, 세션·그룹 평가 | 예측 라벨을 감정·질병의 직접 측정으로 확대하지 않는가 |
| 프로토콜·시료 기록 정리 | 검증 규칙, 검색, 출처를 붙인 LLM 초안 | 원 SOP 대조, 누락·환각 검사 | 실제 조건과 결과를 생성 모델이 만들어내지 않는가 |

**AI에서 직접 책임질 최소 역량.** 데이터의 행·열·단위, 예측 시점, 정답 정의, 독립 표본, 학습/검증/시험 분리, 누수, 과적합, 불확실성, 손실과 평가 지표의 차이를 설명한다. 선형/로지스틱 회귀·트리·사전학습·분할의 적용 조건을 이해한다. 작은 입력에 대한 예상 결과와 실제 코드를 대조한다. 매주 6시간 중 약 2시간은 개념, 3시간은 적용, 1시간은 검증에 둔다.

고급 optimizer의 상세 유도, 대형 모델 처음부터 학습, 새 attention 구조의 설계는 현재 선택 과제다. [기존 ML·DL 심화 문서](ml_dl_depth_plan.md)는 필요할 때 찾아보는 심화 자료로 보존한다. 코드를 AI에 맡겨도 연구 질문·대조군·분할·평가·해석은 연구자가 결정한다.

**논문 목표와 실험 학습을 연결하는 방식.** 기존 P1 음향 리뷰, P2 음향 평가, P3 조직 측정의 질문은 유지한다. 새로 배우는 기법마다 별도 논문을 추가하지 않는다. RNA·단백질·세포배양은 연구 질문과 시료 연결이 있을 때만 논문에 포함한다. 서로 다른 동물에서 얻은 조직과 공개 전사체를 임의로 짝짓지 않는다. 4주차에 교수님과 기여·공동저자 역할·자료·일정을 검토하고 투고 목표를 조정한다. 주 60시간과 새 교육 일정만으로 기존 투고 시한이 보장되지는 않는다.

**논문을 읽을 때의 초점.** 결과 그림 하나를 고른 뒤, 그 그림이 생기기까지 표본→처리→측정→QC→정규화→통계의 경로를 역추적한다. Methods의 각 단계에 위 여덟 질문을 적용하고, 결론을 설명할 다른 원인 하나와 이를 구별할 대조군을 제안한다. 이 과정의 핵심을 300~500자로 쓰는 연습을 인문논술과 연결한다.
