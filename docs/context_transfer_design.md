# SoundWel의 맥락 전이 실험 설계

2026년 10월 12일 개정. 현장 수집 없이 수행하는 탐색적 공개자료 재분석이다. 모델 본 분석은 아직 실행하지 않았다.

## 연구 질문

동일한 평가 발성에 대해, 평가와 같은 상황의 다른 동복 집단을 학습한 모델과 다른 상황만 학습한 모델의 성능을 비교한다. [Lee 2024](https://doi.org/10.1016/j.applanim.2024.106243)의 서로 다른 스트레스 상황 간 지표 관계를 문제의식으로 삼는다. SoundWel의 맥락 기반 Pos/Neg는 코르티솔·회복탄력성·놀람 반응의 정답이 아니다.

이번 설계에서 두 조건 모두 평가 동복 집단을 학습하지 않는다. 따라서 “새 개체보다 새 상황의 비용이 크다”를 직접 검증하는 것이 아니라, **특정 평가 맥락 묶음에서 학습 맥락 구성이 달라질 때의 성능 차이**를 추정한다.

## 두 학습 조건과 두 특징 집합

| 조건 | 학습 자료 | 특징 | 공통 평가 |
|---|---|---|---|
| K1 | Reunion 양성, Restrain 음성 | log 지속시간 | 평가 fold의 Reunion·Restrain |
| K4 | K1과 동일 행 | log Dur, log AMRate, log Q50, 원척도 WienEntrMean | K1과 동일 콜 |
| U1 | AfterNursing·Huddling 양성, Isolation 음성 | log 지속시간 | K1과 동일 콜 |
| U4 | U1과 동일 행 | K4와 같은 네 특징 | K1과 동일 콜 |

- **H1 주질문:** `LBA(K4) − LBA(U4)`가 양수일 것으로 예상한다.
- **H2 보조질문:** `[LBA(K4) − LBA(K1)] − [LBA(U4) − LBA(U1)]`가 양수일 것으로 예상한다. 특징 추가의 이점이 다른 맥락에서 약해지는지를 조사한다.
- 예상과 반대인 결과도 같은 분모·지표로 보고한다. H2의 차이만으로 특징 추가가 유익하다고 결론 내리지 않고 K와 U의 특징 추가 효과를 각각 제시한다.
- 개체 순위 일관성 H3는 첫 원고의 필수 분석에서 제외한다. 일부 신원이 불확실하고 [Leliveld 2017](https://pubmed.ncbi.nlm.nih.gov/28912089/)과 원자료·질문이 겹친다.

## 실제 실험 단위

IASPA의 LF 자료를 대상으로 저자 S1 연결, RecordingSite, 네 특징의 유효성, 원 맥락을 확인한다. Dur·AMRate·Q50가 양수이고 entropy가 유한한 공통 표본을 모든 모델에 사용한다. 원자료와 연결된 문자열 ID 수를 그대로 독립 동물 수로 쓰지 않는다.

Reunion의 원표 ID는 여러 개지만 양성 평가의 배경은 **다섯 LitterID 블록**뿐이다. ID 앞자리 0과 접미 문자가 달라 같은 동물일 가능성이 있는 사례, 발신자를 확정하지 못한 사례가 있어 동복을 분할 단위로 사용한다. [Tallet 2013](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0071841)

같은 동복, 확인된 원 녹음, 모호 ID의 연결은 같은 분할 블록에 둔다. 여러 동복이 연결되면 병합하고 블록 수를 다시 계산한다. 모호 ID를 같은 돼지라고 확정하거나 성별을 자동 수정하지 않는다. 동복이 확인된 발신자 불명 콜은 동복 수준 평가에만 기여한다.

Restrain은 Arms와 Backtest, Isolation은 Isolation·LongIsolation·ShortIsolation의 묶음이다. 원 Context를 별도 열로 보존하고 하위 상황별 결과도 보고한다. placeholder 날짜를 실제 연도·세션으로 사용하지 않는다. 같은 Piglet 연령 범주라도 세부 일령·성별·절차·녹음 조건은 다를 수 있다. 긴 원 녹음과의 완전한 대응이 없으면 세션 독립성까지 주장하지 않는다. 후보 WAV 1,648개는 모두 존재하고 읽기 오류·파일 또는 PCM 기준 완전 동일 복제는 없었다. 부분 중복·유사 파형·공통 원 녹음은 이 검사로 배제하지 못한다.

## 분할과 학습량 일치

기본안은 양성의 다섯 동복 블록을 각각 한 번 평가하는 **고정 5-fold**다. 음성 동복도 같은 fold map에 배정하고 원 맥락·콜 수의 균형을 가능한 범위에서 맞춘다. 메타데이터로만 배정하며 성능으로 fold를 선택하지 않는다.

각 fold에서 평가 동복의 모든 맥락 자료를 두 학습 조건에서 제외한다. 네 모델의 평가 segment ID는 완전히 같아야 한다. U에는 Reunion·Arms·Backtest를 넣지 않는다. 전체 평가 콜은 모델별 OOF 예측에 한 번씩 나타난다.

학습 예산은 조건별·클래스별 4개 블록을 출발안으로 삼는다. 음성은 출처 계열에 따라 1개와 3개 블록으로 층화하고 K/U가 같은 층별 수를 사용한다. 같은 클래스·층에서 K와 U 블록을 고정 난수로 짝짓고 `min(K 콜 수, U 콜 수, 20)`개씩 비복원 추출한다. 두 조건의 클래스별 블록 수와 콜 수를 맞추되, 한 조건 안의 양·음 콜 수가 같다는 뜻은 아니다.

기본 PCG64 seed는 20261012다. 실제 fold·선택 행·짝·입력 hash를 성능 실행 전에 고정한다. M1과 M4는 같은 학습 행을 사용한다. 최종 원 녹음 검사로 코호트가 달라지면 분할·예산을 먼저 개정하며 양성 다섯 블록을 임의로 쪼개지 않는다. 공통 학습 예산이 클래스당 2블록 미만이면 표준 비교를 보류한다. 이 문턱은 검정력 기준이 아니다.

## 모델과 평가

StandardScaler와 L2 logistic regression을 학습 자료에만 적합한다. C=1, solver=lbfgs, max_iter=2000, tol=1e-4, class_weight=balanced, threshold=0.5를 사용한다. 가중치는 학습 행에서만 계산하고 추가 sample_weight는 쓰지 않는다. 초기 튜닝·증강·딥러닝 비교는 없다. context·ID·날짜·성별은 예측 입력이 아니다.

주지표 LBA는 이 연구에서 정의하는 **동복 블록 균형정확도**다. 각 클래스에서 블록별 recall을 동일 가중 평균한 뒤 양·음 두 값을 평균한다. 콜이 많은 동복이 결과를 지배하지 않도록 한다. 계산은 합쳐진 전체 OOF 예측으로 하며 fold별 점수의 단순 평균으로 대체하지 않는다.

`LBA = 0.5 × [mean_block(recall_Pos) + mean_block(recall_Neg)]`

양성 다섯 블록은 정밀도에 큰 제약을 준다. **주결과는 점추정과 블록별 결과이며 p값으로 가설을 채택·기각하지 않는다.** 모든 양성·음성 블록의 K/U 차이를 공개하고, 평가 블록 하나씩을 빼서 계산한 영향도를 제시한다. 이 영향도는 재학습이나 신뢰구간이 아니다. 참고 bootstrap을 제공한다면 모든 모델·클래스의 예측을 같은 블록으로 함께 재표집하고 작은 집단 수에 민감한 조건부 구간으로 표시한다.

call-level BA·macro-F1·클래스 recall·혼동행렬·원 Context별 recall은 보조다. 한 클래스뿐인 원 Context에 이진 BA를 붙이지 않는다. 낮은 차이는 동등성 입증이 아니며 큰 차이도 맥락만의 인과 효과는 아니다.

## 실행량과 원고

주분석은 5-fold×K/U×M1/M4로 **20회 적합**이다. 별도 개발 점검 4회는 논문 성능에 합치지 않는다. 선택적 학습 추출 민감도는 outer fold를 고정하고 20261013~20261016의 네 시드를 모두 실행해 80회를 추가한다. 시드를 독립 반복으로 세거나 가장 좋은 시드로 주결과를 교체하지 않는다.

첫 2주는 자료 감사·원 녹음/중복 확인 → 고정 분할·학습량 매칭 → 개발 점검·20회 분석 → 블록별 결과·민감도 → 재현·내부 검토본 순으로 진행한다. 2주는 실제 착수일부터의 검토본 목표이며 게재·투고 보장이 아니다.

원고 가제는 *Context-bundle transfer of acoustic valence classification in piglets: an exploratory litter-disjoint reanalysis of SoundWel*이다. 자료 흐름, fold별 학습량, 공통 평가의 네 조건, 블록별 차이·영향도를 핵심 표·그림으로 만든다.

## 이전 계획과 신규성

10월 9일의 평균 지속시간·특징 추가·무작위 대 그룹 분할 및 기존 22/7 가설 가족은 이력으로 보존한다. 이번 H1/H2는 별도의 맥락 전이 질문이며 이전 결과를 숨기거나 유리한 검정만 추리지 않는다. fold당 양성 블록이 하나인 현재 안은 이전 최소 평가 그룹 기준에 못 미치므로 정밀한 추론에서 탐색적 집단별 기술로 범위를 변경한다.

현장 관찰 설계는 별도 후속안이다. 이번 원고는 새 현장 자료·장비 구매·ATTD에 의존하지 않는다. 공개자료를 이미 살펴본 이력을 명시하고 외부 미사용 자료나 맹검 사전등록이라고 부르지 않는다.

[Briefer 2022](https://www.nature.com/articles/s41598-022-07174-8)는 음향 특징·상황 분류를, [2026년 프리프린트](https://arxiv.org/abs/2608.02104)는 SoundWel의 identity-aware 평가를 이미 다뤘다. 새 기여 후보는 원 실험 구조·불명 ID를 보존한 분할과 공통 평가·동일 학습량에서의 전이 차이다. 독립 논문으로 충분한지는 실제 결과와 선행연구 대조로 판단한다.
