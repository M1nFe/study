## 1. 본문에서 답할 세 질문

H2/H3의 **1차 예측 대상은 맥락에 근거해 부여된 assumed valence(Pos/Neg)**다. 감정을 직접 측정한 정답이 아니다. 1차 표본은 LF 콜 중 ID·특징·클래스 지원이 확인된 적격 집합으로 정하고 버전을 고정한다. 17개 맥락 다중분류나 LF/HF 전체 분석은 원래 계획에 있으면 별도 탐색/부록으로 구분한다. 아래 ‘맥락 라벨 예측’은 이 Pos/Neg 과제를 뜻한다.

| 질문 | 최소 분석 | 판정에 필요한 것 | 해석 범위 |
|---|---|---|---|
| **H1.** 같은 팀·LF 콜 안에서 긍정 맥락의 발성 지속시간 감소가 반복 구조를 반영해도 유지되는가? | 원계획의 팀별 대비 유지; log(duration) 혼합모형과 그룹×조건 평균 민감도 분석 | 지속시간 비율과 95% CI, 개체/쌍 수, 조건별 표본, 적합 실패 | 맥락 관련 연관성. 짧은 콜을 긍정 감정이나 높은 회복탄력으로 치환하지 않음 |
| **H2.** AMRate·Q50·엔트로피가 지속시간보다 추가 예측 정보를 주는가? | majority 기준선, duration-only, duration+3특징의 단순 모델; 검증된 그룹 제외 평가 | 같은 평가 콜·외부 fold에서 balanced accuracy 차이; macro-F1·클래스별 recall 보조 | 새 개체/쌍 또는 명시한 세션에서 맥락 라벨을 예측하는 정보 |
| **H3.** 무작위 콜 분할과 그룹·팀 분할에서 결론이 얼마나 달라지는가? | 동일 특징·모델·선택 규칙으로 적격 분할 비교 | 공통 표본과 팀별 결과, 그룹 단위 불확실성, 제외 사유 | 각 평가가 겨냥한 전이 조건. 하락분 전체를 누수나 장비 영향으로 해석하지 않음 |

H1은 ETHZ·FBN·NMBU·IASPA 등 **기존 계획의 대비를 유지하되 적격성부터 확인**한다. FBN의 조건화 비교처럼 정의가 다른 맥락을 결과에 맞춰 합치지 않는다. AMRate는 콜 내부 진폭 변조율, Q50은 스펙트럼 에너지의 중앙 주파수다. 각각 시간당 발성률과 기본주파수 F0가 아니다. LF/HF 구분에 Q50이 사용됐다면 Q50 효과의 해석도 그 정의에 조건화된다. [원자료 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC8901661/) · [공개 데이터](https://zenodo.org/records/8252482)

**기존 30가설은 보존한다.** 세 질문은 본문을 구성하는 방식이지 유리한 검정만 선택하기 위한 새 보정 가족이 아니다. 기존 주가설·탐색가설·기술분석의 구분과 모든 검정/미검정 사유를 부록에 남긴다. 이미 본 예비 결과와 계획 수정 시점을 기록하며, 이번 계획을 결과를 전혀 보기 전의 확증 사전등록이라고 부르지 않는다.

## 2. 첫 72시간: 데이터를 더 돌리기 전에 통과할 세 관문

달력 3일 안에 **분석 12–16시간, 원문 읽기·Methods 작성 6–8시간**을 배정하는 계획이다. 기존 주 60시간 안의 재배분이며, 72시간 연속 작업을 뜻하지 않는다. 외부 자료 확보가 늦어지면 Methods·표 틀과 현장 SOP를 병행한다.

| 시점 | 바로 할 일 | 남길 파일·표 | 통과 기준 / 실패 시 처리 |
|---|---|---|---|
| **D1: 정본 고정** | 공개 데이터 버전·해시, 저자 S1 원본, 키 특징·라벨 정본, 원본 녹음 관계 확인. 기존 결과를 본 이력 정리 | 데이터 사전, 자료 흐름 초안, 계획 변경 이력, S1 연결 보고서 | 예상 연결 수를 실적으로 쓰지 않음. 실제 조인에서 중복키·다중매칭·불일치·미매칭을 구분 |
| **D2: 단위 검증** | 팀×ID×조건×세션 교차표. NMBU의 저자 ID가 개체인지 녹음 쌍인지 확인. 특징별 결측·녹음 품질 정리 | 적격성 표, 쌍 매핑 근거, 결측·제외 표 | NMBU에 `pair`라는 이름만 붙이는 것으로 완료하지 않음. 같은 쌍이 다른 그룹으로 나뉘지 않아야 함 |
| **D3: 분석 계획 고정** | 적격 표본·분할 목록·전처리·튜닝 범위·추정 단위·부트스트랩·FDR 정책을 버전으로 고정. 작은 검증 실행 | 분할 manifest, 설정 스냅샷, 실행 로그, Methods 초안 | 금지된 그룹 공유 0건, 학습 fold 밖 적합 0건, 공통 평가 행 확인. 이후 변경은 이유와 영향을 기록 |

**ID 관문에서 막히면:** 불명 ID를 파일명으로 만들거나 전부 학습에 넣어 개체 독립성을 확보했다고 하지 않는다. 검증된 ID 부분집합의 분석과 제외 편향을 보고한다. 세션만 확인되면 세션 평가로 범위를 낮춘다. 날짜·세션도 불확실하면 해당 주장의 분석을 보류하고 기술통계와 자료 감사까지만 쓴다.

## 3. D4–D14: 분석과 집필을 같은 날 진행

첫 2주는 작은 적격 부분집합에서 추정·분할·출력의 타당성을 확인하고, 미검정 빈칸을 포함한 내부 검토본을 만든다. 커리큘럼 W3–W4에는 범위가 고정된 핵심 분석과 민감도 검토를 완성한다. 이 둘을 별개의 성과처럼 중복 계산하거나 첫 부분집합의 점수를 최종 결과로 사용하지 않는다.

| 기간 | 분석·검증 | 같은 날 쓸 원고 | 완료 증거 |
|---|---|---|---|
| **D4–D5** | H1 팀별 지속시간 효과. 개체 내/간 대비 구분, 그룹 평균 민감도, 잔차·수렴·희소 그룹 검토 | 데이터와 반복 단위, H1 Methods, 결과 표의 빈칸 채우기 | 팀별 효과 그림, 분석/제외 그룹 수, 실패한 대비까지 포함한 표 |
| **D6–D7** | H2 duration-only 대 4특징. 먼저 단일 단순 분류기로 고정된 분할에서 실행 | 특징·전처리·모델 선택·지표 Methods, H2 Results | 공통 표본 기반 성능차, 클래스별 결과, 그룹 불확실성 |
| **D8–D9** | H3 random/group 평가. 조건이 되는 경우에만 session/team 제외 평가 | 평가 조건별 질문, H3 Results, domain shift 제한 | 분할별 비교 그림, 각 fold 적격성, 없는 클래스·평가 불가 조건 목록 |
| **D10–D11** | 결측·불명 ID 제외·희소 맥락·오류 원인 민감도. 같은 개체/쌍의 두 조건을 함께 재표집하는지 확인 | 불확실성·선택 편향·이력 공개, Lee 연구와 연결하는 Discussion | 실패 조건 표와 기존 가설 전체 부록. 새 유리한 분석을 주분석으로 교체하지 않음 |
| **D12** | 고정 코드·설정·입력에서 표·그림 재생성. 한 명이 원문/라벨·단위와 Methods 대조 | 재현성·데이터 접근·한계 | 실행 환경·버전·분할·결과 연결, 재생성 대조 기록 |
| **D13–D14** | 분석 질문을 유지할지 축소할지 결정. 다음 실험 하나만 선정 | 제목·초록·결론을 실제 결과 범위로 작성, 내부 검토본 완성 | 그림 4개 또는 명시한 보류 사유, 표 4개 틀/실측값, 내부 검토 질문 |

자료 부족으로 멈춘 분석은 숫자 대신 **“미검정—사유”**를 남긴다. 내부 검토본에는 Methods·자료 감사·확인 가능한 결과·남은 일을 모두 포함할 수 있다. 식별자 검증이 끝나지 않았는데 분류 점수만 채워 일정 완료로 처리하지 않는다.

2주 후에는 다음 중 하나를 선택한다.

- **진행:** 검증된 단위와 분석이 재현되고, 선행연구와 비교해 추가로 알게 된 점이 있다. 원고 수정과 필요한 최소 분석을 진행한다.
- **축소:** 일부 팀/가설의 단위·정밀도가 부족하다. 가능한 범위와 미검정 사유를 명시해 평가 민감도·자료 감사 연구로 조정한다.
- **후속 수집 우선:** 확인 가능한 새 기여가 부족하다. 분석 패키지를 방법 준비 성과로 보존하고 현장 데이터 품질·행동 관측을 우선한다.

높은 정확도나 `p<0.05`는 이 결정의 단독 기준이 아니다. 비유의성은 효과 부재의 증명도 아니다. 동등성을 주장하려면 의미 있는 동등성 구간과 충분한 정밀도가 별도로 필요하다.

## 4. 최소한으로 고칠 분석 엔진

이 저장소는 실행 코드를 제공하지 않는다. 아래 변경은 기존 엔진의 실제 명령·환경·테스트를 확인한 뒤 별도 연구 프로젝트에서 수행한다. 과거 스모크가 통과한 사실과 현재 과학적 분석이 유효한지는 별개의 문제다.

| 우선순위 | 확인·수정 범위 | 실제 검증 |
|---|---|---|
| 1 | 저자 S1 연결과 NMBU 쌍 매핑 | 원본 키와 결합된 행 수 대조, 잘못된/모호한 매칭 분리, pair 분할 비중첩 |
| 2 | split manifest와 pipeline | 분할을 먼저 고정하고 증강·결측 대체·표준화·특징 선택·튜닝은 학습 fold 안에서 적합 |
| 3 | H1의 반복 구조와 불확실성 | 같은 그룹이 양 조건에 있으면 그 짝을 보존한 cluster bootstrap; 독립 조건이면 실제 단위에 맞는 재표집 |
| 4 | H2/H3의 평가 행 일치 | 모든 비교 모델의 sample ID·외부 fold 동일, 없는 클래스와 실패 fold를 숨기지 않음 |
| 5 | FDR와 전체 가설 export | 사전 정의한 가족, 계획 수·검정 수·미검정 수·보정 정책을 출력; 결과 뒤 가족 축소 금지 |
| 6 | 보고서 재생성 | 그림/표 숫자의 입력·run·설정 추적; 스모크 산출물을 본 분석 결과로 사용하지 않음 |

현재 BH 구현이 유한한 p값만 대상으로 삼는다면 **계획된 모든 가설을 보정한 값과 같지 않다.** 검정 가능성 결정은 결과의 유의성에 의존하지 않게 하고, 실제 검정 가족의 정의와 미검정 이유를 기록한다. 정책을 바꿀 때는 변경 이력을 남기고 전체 결과에 일관되게 적용한다.

기존 pDFA처럼 같은 개체/그룹에서 일부 콜을 학습하고 나머지를 평가하는 설계는 알려진 그룹 내 질문에 해당한다. H2/H3의 **새 개체/쌍 성능**과 별도 결과로 표시한다. 생물학적 반복 단위는 seed가 아니며, 여러 seed의 표준편차를 개체·돈방 수준 신뢰구간으로 사용하지 않는다.

| 항목 | 고정할 규칙 |
|---|---|
| 그룹 분할 | 저자 근거로 확인한 개체/쌍 단위. 일부 개체가 공유되는 세션이면 목표에 맞게 상위 그룹을 구성하거나 교차 구조를 명시 |
| 팀 제외 평가 | 팀별 두 클래스와 충분한 그룹 지지 여부를 먼저 확인. 팀은 자동으로 농장과 같지 않음 |
| 공통 맥락 | 같은 정의·콜유형의 맥락이 팀 간 겹치는지 확인. 한 클래스만 남으면 이진 일반화 평가를 강행하지 않음 |
| 비교 표본 | H2는 duration-only와 4특징 모델의 공통 적격 콜이 1차. H3도 가능한 공통 평가 범위를 맞추고 표본 변화는 별도 표로 표시 |
| 결측 | 특징×팀×맥락×조건 결측표. 공통 완전자료 분석과 사전 지정한 대체/확대 분석을 구분. 팀 전체에 없는 특징을 임의 추정해 생물학적 값으로 취급하지 않음 |
| 전처리 | 학습에서만 적합. 원본 보존; 잡음 제거가 AMRate·엔트로피를 바꾸는지 별도 검토 |
| 지름길 점검 | `context`를 assumed valence 예측 입력으로 넣지 않음. LF 팀내 분석에서 상수인 team/age는 설명 변수가 될 수 없음 |
| 이력 | 이미 관찰한 데이터/평가 점수는 탐색 이력 공개. 분할을 새로 만든 사실만으로 완전히 보지 않은 외부시험이 되지 않음 |

**새 모델은 마지막이다.** 핵심 결과가 재현되면 기존 MFCC와 캐시된 동결 PANNs를 같은 선형 분류기·표본·분할로 비교할 수 있다. 그다음 필요한 경우 Perch 2.0 하나만 추가한다. 짧은 콜의 패딩·입력 길이가 duration 지름길을 만들 수 있어 길이 기준선을 유지한다. 추가 성능뿐 아니라 계산 시간과 표본 손실도 보고한다. [Perch 2.0](https://arxiv.org/abs/2508.04665)

4. **Discussion:** 남는 신호와 조건 의존성, 선행 연구보다 추가한 점, 맥락·정서·반응·회복탄력의 구분, 현장 후속 질문.

## 7. 후속 현장 관찰의 계획 이력

아래는 한 돈방을 대상으로 작성했던 관측 항목의 이력이다. 현재 실행은 [10월 16일 전체 계획](data_collection_master_plan.md)의 **두 돈방·총 4대·SD 연속 기록·선정 12일 장기 보존**을 따른다. 이전 약 8×15m 치수는 현재 두 돈방의 실측값이 아니다. ATTD·새 놀람 유발·추가 채혈은 현재 계획에 포함하지 않는다.

| 먼저 확보할 것 | 기록할 내용 | 검증할 질문 |
|---|---|---|
| 원본과 공통 시계 | recording/event ID, 카메라·마이크, 시작/끝, 동기 오차·드리프트, 파일 누락 | 같은 소리와 행동을 같은 사건으로 연결할 수 있는가? |
| 독립 행동 라벨 | 누움·서있음·이동·급이기 접근, 접촉/싸움 사건, 가림, 관찰자·확신도 | 음성 모델 출력 없이 관찰해도 행동이 반복 가능하게 분류되는가? |
| 배경·미탐 표본 | 모델 탐지 구간과 탐지 밖 임의 시간창, 기계음·사람·다른 펜 소리 | 검출 후보의 정확도뿐 아니라 놓치는 사건도 알 수 있는가? |
| 음향 사건 | 시작/끝, 겹침·잡음·콜유형 불명, 발신 개체 또는 unknown | 두 마이크의 같은 콜을 한 사건으로 중복 제거할 수 있는가? |
| 시험·환경 대장 | 실제 급이 단계와 시각, 취급·환기·온습도, 기존 체중·섭취 자료의 단위 | 시간대·환경 변화와 사양단계 변화를 구분해 기록했는가? |

우선 결과는 **동기화·라벨 일치도·누락률과 돈방 단위 행동/발성 궤적**이다. 한 돈방의 반복 관측을 30개 독립 처리 반복으로 계산하지 않는다. 개체 발신자가 불명확한 음성에 개체별 체중을 임의 연결하지 않는다. 독립 돈방이나 배치 없이 처리의 인과효과·범용 회복탄력을 입증할 수는 없다.

현장에서는 연속 시간자료가 생긴 뒤에야 발성률, 사건 후 행동 재개 시간, 기준선 편차를 정의할 수 있다. 급이 제한→재급이의 여러 날 변화는 놀람 직후의 짧은 반응과 다른 시간척도다. 관찰창에서 회복하지 않은 경우는 미회복/검열로 남기고, 파일 누락·가림·무발성·무반응을 서로 다른 상태로 기록한다. SoundWel의 선별된 콜 길이를 회복 시간으로 쓰지 않는다.

현장 시작일이 2주 분석 일정 중 먼저 온다면 수집 설치·동기 확인·원본 보존을 우선한다. 그 기간의 공개자료 분석을 뒤로 옮기고, 추가 모델 실험으로 재수집할 수 없는 현장 기준선을 놓치지 않는다.
