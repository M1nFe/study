**선택 자료 · ML·DL을 이해하고 연구에 사용하는 심화 과정**

**보존 자료 안내:** 2026-09-29에 작성한 ML 집중 과정이다. 2026-10-01부터 실험·프로토콜 원리를 중심으로 전환했으며, 이 문서의 주 20시간·320시간·16주 과제는 현재 필수 시간표가 아니다. 필요한 개념·진단만 선택해 현재 AI 6시간 블록에서 활용한다. [현재 연구 방향](research_orientation.md)을 우선한다.

**기존 과정의 참고 기준:** [52주 상세 계획](../curriculum.md)에 교재 범위·요일별 활동·과제·통과 기준을 정리했다. 아래의 큰 일정과 주차 순서가 다르면 상세 계획을 따른다. 실제 시작일에 맞춰 달력 날짜를 이동한다.

2026-09-29 보강. 대상은 석사 2학기차, 총 연구·공부 주 60시간, 돼지 음향·장 조직 분석을 진행하는 연구자다. 기존 [연간 계획](roadmap.md)의 논문 세 편을 유지하면서 ML·DL의 수학·구현·연구 설계를 강화한다. 학습 시간은 기존 60시간을 재배분하며 추가하지 않는다. ML·DL의 배경과 평가 원칙은 이 문서를 참고하고, 현재 실행 순서는 52주 상세 계획을 따른다.

목표는 **새로운 논문의 방법을 이해하고, 필요한 부분을 구현하고, 자신의 자료에 적용해도 되는 이유와 안 되는 이유를 설명하는 능력**이다. 논문 편수와 이 능력은 따로 평가한다. 대학의 순위나 강의 수강 여부로 개인 연구 역량을 판정하지 않는다. 이 과정의 평가 기준은 개인 학습을 위해 제안한 것이며 특정 대학의 공식 합격 기준은 아니다.

**ML·DL과 현재 연구의 관계.** 머신러닝은 데이터로부터 예측·구조·표현을 학습하는 방법의 범주이고, 딥러닝은 여러 층의 신경망으로 표현과 함수를 학습하는 머신러닝의 한 분야다. 바이오인포매틱스는 생물학적 데이터와 질문을 다루는 분야로 통계·알고리즘·ML·DL을 함께 활용한다. 축산학은 무엇을 측정하고 어떤 변화를 의미 있게 볼지 결정할 생물학적 기반이다.

| 현재 과제 | ML·DL 방법 | 반드시 이해할 개념 | 연구에서의 함정 |
|---|---|---|---|
| 음성 특징으로 맥락 분류 | 로지스틱 회귀, SVM, 트리·부스팅 | 확률 모형, 규제, 특징 스케일, 결정 경계, 검증 | 같은 녹음 조건을 알아맞혀도 높은 점수가 나올 수 있음 |
| 음성에서 특징 학습 | CNN, PANNs, 전이학습, 이후 attention | spectrogram, 표현, receptive field, 동결/미세조정 | 사전학습 모델의 좋은 점수가 돼지의 감정을 직접 검증하지 않음 |
| 융털·음와 분할 | U-Net, nnU-Net | convolution, 역전파, loss, 클래스 불균형, segmentation | 높은 픽셀 지표와 정확한 길이 측정은 다를 수 있음 |
| RNA-seq | GLM, 차원 축소, 필요시 예측 모델 | likelihood, count 분포, PCA, 다중검정, batch | 적은 표본과 많은 유전자, 처리와 배치의 혼동 |
| 다음 단계의 분만 영상 | 사건 검출, 시계열·시각 표현 | 시간 의존성, 검출 문턱, 이벤트 평가 | 많은 프레임이 많은 독립 분만 사건을 뜻하지 않음 |

**모든 모델을 여섯 부분으로 분해해서 배운다.** 데이터와 표본 생성 과정 → 표현과 모델 → 목적함수 → 최적화 → 모델 선택 → 새로운 대상에서의 평가다. 수식이나 코드가 이 흐름의 어디에 속하는지 말할 수 있어야 한다.

대표적인 지도학습 문제는 다음과 같이 쓸 수 있다.

$$
\hat\theta=\arg\min_\theta\left\{\frac{1}{n}\sum_{i=1}^{n}\ell\bigl(f_\theta(x_i),y_i\bigr)+\lambda\Omega(\theta)\right\}.
$$

여기서 x는 입력, y는 관측 라벨, f는 모델, theta는 학습 파라미터, loss는 오차의 정의, Omega는 규제, lambda는 그 강도다. n은 이 식에서 손실을 평균하는 관측 수이며, 통계적으로 독립적인 동물 수와 항상 같지는 않다. 관측 구조에 따라 가중치·표집·평가 단위가 달라진다. 이 식은 대표적인 형태이며 모든 ML 방법의 완전한 정의는 아니다.

선형 모델을 신경망으로 바꾸는 것, loss를 바꾸는 것, SGD를 Adam으로 바꾸는 것, train/test를 다시 구성하는 것은 서로 다른 변경이다. 논문의 기여가 그중 어디에 있는지 구별한다. 이것이 모델 이름을 넘어 이해하기 위한 첫 지도다.

**한 개념을 이해했다고 판정하는 다섯 가지 증거.** 각 단원에서 아래를 모두 남긴다.

| 능력 | 남길 증거 | 로지스틱 회귀의 예 |
|---|---|---|
| 설명 | 자료 없이 3~5분 설명 | 선형 점수를 확률로 연결하는 이유와 이진 라벨 가정 |
| 유도 | 정의에서 핵심 식까지 전개 | Bernoulli likelihood → 음의 로그우도 → gradient |
| 구현 | 작은 입력에서 직접 확인 가능한 코드 | NumPy로 loss·gradient·학습 루프 작성 |
| 검증 | 손계산·수치 미분·기준 구현과 비교 | 유한 차분 gradient와 scikit-learn 비교, 설정 차이 기록 |
| 전이 | 내 문제의 가정·한계·실험을 설명 | 음향 특징에 적용할 때 그룹 분할과 규제를 정하는 이유 |

처음부터 모든 알고리즘을 라이브러리 없이 다시 만들 필요는 없다. 직접 구현 대상으로 선형회귀, 로지스틱 회귀, 2층 MLP, 간단한 attention을 선택한다. CNN·U-Net은 PyTorch 기본 층을 조합해 구조와 학습을 이해한다. 나머지는 검증된 구현을 사용하고 가정·입출력·평가를 깊게 확인한다.

**학습 자료는 역할을 나누어 사용한다.** 동시에 여러 강의를 처음부터 끝까지 듣지 않는다. 각 주차의 핵심 질문에 필요한 부분을 읽고 문제·구현으로 확인한다.

CS229는 Python/NumPy, 확률, 다변수 미적분, 선형대수를 선수 지식으로 제시한다. 이 선수 기반부터 필요한 만큼 보충한다. 현재 수업의 일부 자료는 재학생 접근이 필요하므로 공개 강의노트와 공개 과제를 사용한다. 강의 영상 접근 가능성과 학점·채점 지원은 별개다. [CS229 공식 안내](https://cs229.stanford.edu/), [CS231n 공식 안내](https://cs231n.stanford.edu/)

05주의 모의 자료는 통계 개념을 확인하는 학습 자료다. 실제 돼지 성능으로 보고하지 않는다. 12주의 작은 자료 과적합은 학습 파이프라인 점검이며 일반화 성능 평가가 아니다. 현재 연구의 잠긴 시험 자료에는 이 연습을 수행하지 않는다. 14주의 합성 신호도 신호 처리 검증에만 사용한다.

**이후 8개월은 실제 연구 질문을 더 깊게 파고든다.** 모든 주제에서 결과를 본 뒤 최종 시험을 다시 튜닝하지 않는다. 탐색은 개발 자료에서 하고 최종 주장은 고정된 평가에서 검증한다.

| 10개월 | 재현 연구와 독립 평가 | 다른 배치·자료에서 결론이 유지되는가? | 재현 패키지와 실패 조건 |
| 11개월 | 연구 질문의 정교화 | 라벨 부족·녹음 조건 변화·측정 오류 중 해결 가치가 가장 큰 것은? | 질문 하나의 연구 제안서 2쪽 |
| 12개월 | 구두 방어·코드 독해·타인 재현 | 모델의 가정과 한계를 질문받아도 근거로 답할 수 있는가? | 공개 가능한 기술 보고서와 다음 단계 연구계획 |

자기지도학습·Transformer를 배웠다고 반드시 세 논문에 추가하지 않는다. 어떤 실패를 해결할지 먼저 정한다. 생성모델·강화학습은 현재 연구에 필요한 문제가 생기면 이후 깊게 공부한다. 분야의 존재와 핵심 원리는 알아두되 첫 16주의 시간을 분산하지 않는다.

**주 60시간을 다시 배분한다.** ML 기초를 강화하되 조직 기준값과 원고 완성도 계속 진행한다.

|---|---:|---:|---|

| 축산·생물학·오믹스 학습 | 6h | 8h | 장 생물학, 통계적 전사체 분석, 분자 해석 |

첫 16주의 실제 연구 22시간은 예를 들어 실험·분석 14시간, 수동 측정·주석·QC 8시간으로 배분한다. 투고 주간은 이론 일부를 글쓰기로 옮기고 다음 주에 되돌린다. 일요일은 정규 일정을 비워 둔다. 학습이 밀리면 원고 마감을 숨기거나 분량을 두 배로 쌓지 않고 다음 주 선택 과제를 줄인다.

**첫 주 ML 20시간의 실제 구성.** 나머지 40시간은 위 표의 생물학·문헌·연구·원고에 쓴다.

| 시간 | 행동 | 결과 |
|---|---|---|
| 2h | 아래 진단 90분과 채점/공백 기록 | 모르는 항목 목록, 다음 단원 조정 |
| 5h | MML의 벡터·행렬·선형변환 선택 읽기와 문제 | 손으로 푼 연산과 각 축의 의미 |
| 3h | Xw+b와 norm/거리의 기하학적 설명 | 1쪽 개념 지도 |

| 6h | NumPy 구현, 손계산 비교, indexing/broadcasting 실수 찾기 | 작은 예제 코드와 결과 |
| 2h | 자신의 메타데이터 읽기·결합 키/shape 검사 | 실제 데이터가 담기는 행렬의 설명서 |

**진단은 90분, AI와 해설을 보지 않고 먼저 푼다.** 아직 배우지 않은 항목에서 막히는 것은 학습 순서를 정할 정보다. 현재 수준을 진단 결과 없이 단정하지 않는다. 각 문제는 답만 쓰지 말고 이유와 확인 방법을 적는다.

1. X의 shape이 (8,3), w가 (3,), b가 scalar일 때 Xw+b의 shape은? X의 행·열이 현재 연구에서 무엇을 의미할 수 있는가?
2. MSE를 `(1/(2n)) ||Xw-y||²`로 정의했을 때 w에 대한 gradient를 유도하라. 각 항의 shape을 쓰라.
3. 유병률 1%, 민감도 90%, 특이도 95%인 가상 검사에서 양성 결과가 실제 양성일 확률을 10,000명 표로 계산하라. 이는 실제 임상 검사의 수치가 아닌 확률 연습이다.
4. Bernoulli 확률에서 binary cross-entropy를 유도하라. 확률 0.9가 실제로 무엇에 대해 보정된 확률인지 설명하라.
5. 학습 자료 전체와 평가 자료를 합쳐 표준화한 뒤 분할했다. 무엇이 문제이며 어떻게 고칠 것인가?
6. 같은 동물의 이미지들이 train/test에 섞였다. 높은 성능으로 어떤 주장을 할 수 있고 어떤 주장을 할 수 없는가?
7. train loss는 내려가지만 validation loss가 올라간다. 가능한 원인과 확인할 증거를 순서대로 제시하라.
8. 입력 64×64, 입력 채널 3, 출력 채널 16, kernel 3×3, stride 2, padding 1, dilation 1, bias 있음인 convolution의 출력 크기와 파라미터 수를 계산하라.
9. 2층 MLP에서 한 가중치에 loss가 전달되는 미분 경로를 chain rule로 그려라.
10. U-Net의 foreground Dice가 좋아져도 villus height 오차가 나빠질 수 있는 예를 설명하라.
11. 동결 PANNs+로지스틱 회귀와 PANNs 전체 미세조정에서 학습되는 파라미터, 필요한 데이터, 과적합 위험을 비교하라.
12. 새 방법이 기준 방법보다 macro-F1이 높다. 모델 선택·튜닝 예산·평가 그룹·불확실성·실용적 의미 중 무엇을 확인해야 개선을 주장할 수 있는가?

문제마다 0=설명하지 못함, 1=일부 설명하지만 중요한 오류가 있음, 2=계산/개념과 근거를 일관되게 설명함으로 기록한다. 총점으로 대학 수준을 환산하지 않는다. 1~4의 공백은 수학·확률, 5~7은 실험 설계, 8~11은 DL·표현학습, 12는 연구 판단 보충에 사용한다. 같은 문제의 답을 외우는 대신 4주 후 숫자와 조건을 바꿔 다시 푼다.

**4·8·12·16주에 평가한다.** 해설을 보고 이해한 느낌과 독립적으로 푸는 능력을 구분하기 위한 절차다.

| 시점 | 평가 | 진행 기준 |
|---|---|---|
| 4주 | 선형/로지스틱의 손실·gradient 유도, NumPy 구현, 작은 예제 검증 | 핵심 계산 오류가 없고 입력·출력·가정을 설명 |
| 8주 | 잘못된 ML 파이프라인 감사, 모델 비교와 PCA 설명 | 누수·잘못된 선택·지표 오해를 찾아 수정 |
| 12주 | MLP 역전파, CNN 크기 계산, 학습 실패 진단 | gradient 검증과 학습/평가 모드의 역할 설명 |
| 16주 | 자기 연구 모델 20분 발표와 질의응답, 핵심 코드 일부 재작성 | 수식·구현·검증·생물학적 해석을 연결하고 모르는 부분을 정확히 표시 |

통과하지 못한 항목은 다음 1~2주의 선택 학습 시간을 사용해 보완한다. 연구 전체를 멈추거나 어려운 개념을 건너뛴 채 새 모델을 계속 추가하지 않는다. 분기마다 지도교수나 실제 해당 분야를 아는 연구자가 한 번은 검토한다. AI의 채점은 보조 의견으로 활용한다.

**ML·DL 원저는 문제와 실험의 논리를 읽는다.** 초반에는 교재로 기초를 만들고 아래 순서로 연구 논문을 읽는다. 최신 모델 목록을 외우는 식으로 읽지 않는다. 아래 질문과 과제는 이 학습 계획을 위해 제안한 것이다.

| 시기 | 논문 | 읽을 질문 | 구현·재현의 범위 |
|---|---|---|---|
| 12주 | He 등, [Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385) | 깊이를 늘릴 때 최적화 문제와 일반화 문제를 어떻게 구분했는가? | 작은 residual block과 비교 설계. 원 논문의 대형 실험 재현을 첫 목표로 삼지 않음 |

| 15주 | Kong 등, [PANNs](https://arxiv.org/abs/1912.10211) | 사전학습 표현은 무엇을 배웠으며 돼지 음성으로 옮길 때 무엇이 달라지는가? | 공식 가중치·입력 규격 확인, 동결 특징 분석 |

재현은 원 논문의 데이터·설정·척도가 일치하는 범위에서만 그렇게 부른다. 작은 데이터의 개념 실험은 “축소 실험” 또는 “원리 확인”으로 기록한다. 새로운 데이터로 확장한 결과와 원 결과의 재현을 구분한다.

**개념 하나를 깊게 파는 예: 로지스틱 회귀.** 한 단원에서 아래 깊이까지 가면 다음 단원에도 같은 방식을 적용할 수 있다.

1. 목표를 정한다. 이진 라벨 y가 주어졌을 때 입력 x에 조건부인 확률을 추정한다.
2. 가정을 쓴다. log-odds를 입력의 선형 함수로 모델링한다. 특징과 가중치의 의미를 명시한다.
3. 식을 유도한다. `p=sigmoid(Xw+b)`, Bernoulli likelihood에서 평균 cross-entropy가 나온다. 규제가 없을 때 w의 gradient는 `X.T @ (p-y) / n`이다.
4. 작은 데이터로 구현한다. 안정적인 loss 계산, gradient, 한 번의 업데이트를 손계산과 대조한다. 수치 미분으로 오류를 찾는다.
5. 조건을 바꾼다. 특징 스케일·L2·불균형·표본 수를 바꾸고 결과를 실행 전에 예측한다.
6. 기준 구현과 비교한다. intercept·규제 강도·loss 평균 방식·solver 종료 조건이 같은지 확인한다.
7. 내 자료에 적용한다. MFCC의 의미, 녹음 세션, train-only 표준화, 클래스별 오류를 검토한다.
8. 결론의 범위를 쓴다. 분류가 잘된다는 것과 해당 특징이 정서의 인과적 지표라는 것은 별도 근거를 요구한다.

**바이브 코딩에는 독립적인 시도와 검증 시간을 넣는다.** 핵심 구현 8시간 중 첫 시도와 나중 재구성에 합계 최소 3시간을 배정한다. 문법 확인·오류 메시지 해석은 도움을 받을 수 있지만, 자신의 손실·gradient·분할 결정을 설명하기 전에 완성 코드만 받아 실행하지 않는다.

추천 흐름은 ① 직접 정의/그림/예상 결과 작성 → ② 작은 구현 시도 → ③ AI에게 힌트·오류 위치 요청 → ④ 수정과 검증 → ⑤ 하루 뒤 원리를 보지 않고 핵심을 재구성이다. 시간만 채우지 말고 이전에는 못 했던 설명·계산·오류 진단이 가능한지 확인한다.

```text
이번에는 내 ML·DL 이해를 훈련하는 튜터로 도와줘.
주제는 [개념], 내 현재 설명/유도/코드는 [내용]이다.
처음에는 완성 답안이나 전체 코드를 주지 말고 내 답을 진단해라.
틀린 가정이나 막힌 지점을 하나씩 짚고 최소 힌트부터 줘라.
필요하면 작은 수치 예제로 설명하고, 내 예측을 받은 뒤 결과를 보여줘라.
해설을 한 다음에는 숫자·조건이 다른 문제로 다시 확인해라.
마지막에 설명·유도·구현·검증·내 연구 적용 중 아직 부족한 것을 기록해라.
```

실제 논문용 코드에서는 검증된 라이브러리를 우선 사용한다. 학습용 수제 구현이 상용·공식 구현보다 신뢰성이 높다고 가정하지 않는다. 데이터 누수·개체 중복·단위 오류 같은 과학적 검증과 수치 정확성 검증을 함께 수행한다.

**1년 뒤 비교할 산출물.** 다음 여섯 가지를 실제로 보여줄 수 있는지 점검한다.

- 손실·gradient·규제·일반화의 핵심을 자료 없이 설명한 기록.
- 선형회귀·로지스틱·MLP·attention의 작은 구현과 검증.
- CNN/U-Net/PANNs의 입출력·학습·실패 원인을 분석한 노트.
- 데이터 계층과 모델 선택을 반영한 공정한 비교 실험.
- 논문의 중요한 주장 하나를 재현하고 한계 또는 확장 질문을 검증한 보고서.
- 동물 생물학과 측정 타당성까지 연결해 자신의 연구를 방어하는 발표.

이 산출물이 쌓이면 강의 수강량과 관계없이 무엇을 할 수 있게 되었는지 확인할 수 있다. 이후 ML 자체의 새 방법을 연구하려면 선택한 세부 주제에서 이론·경쟁 방법·평가 근거를 더 깊게 쌓는다. 첫해에는 현재 데이터의 어려운 문제 하나를 끝까지 설명하고 검증하는 경험을 만든다.
