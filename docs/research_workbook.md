**연구 실행 워크북 — 석사 2학기차·주 60시간**

**이번 실행의 기준:** [52주 상세 계획](../curriculum.md)에 교재 범위·요일별 활동·과제·통과 기준을 정리했다. 아래의 큰 일정과 주차 순서가 다르면 상세 계획을 따른다. 실제 시작일에 맞춰 달력 날짜를 이동한다.

사용법: 아래 양식을 프로젝트마다 복사한다. `[ ]`는 아직 확인되지 않은 항목이다. AI가 채운 답도 원자료·원문·실행 결과와 대조하기 전까지는 확인된 사실로 표시하지 않는다. 전체 일정은 [roadmap.md](roadmap.md)에 있다.

**1쪽 연구헌장.** 분석을 시작하기 전에 작성하고 변경 날짜와 이유를 남긴다.

```text
프로젝트 / 날짜 / 버전:
한 문장 질문:
이 질문이 동물·농장·연구에 중요한 이유:
예측 또는 추정하고 싶은 대상:
직접 측정하는 관측값과 라벨:
관측 단위 / 독립 표본 단위 / 처리 배정 단위:
자료 출처 / 사용 권한 / 실제 접근 가능한 위치:
원자료 버전·체크섬 / 메타데이터 사전:
주 가설:
가장 강한 대안 설명:
가설을 틀렸다고 판단하게 할 결과:
핵심 비교 또는 최소 실험:
기준 방법:
주 평가 지표 / 보조 지표 / 선택 이유:
허용 오차 또는 실질적으로 의미 있는 차이와 근거:
개발 자료 / 모델 선택 자료 / 최종 평가 자료:
이미 보거나 선택에 사용한 자료:
독립 평가가 가능한 대상 / 불가능한 대상:
처리할 교란 / 처리할 수 없는 교란:
불확실성 추정과 재표집의 단위:
표본 수의 근거 / 부족할 때 주장 범위:
계산 예산 / 사람의 측정 시간 / 완료 조건:
하지 않을 주장:
결과가 좋지 않아도 남길 과학적 정보:
지도교수·협력자 검토 내용:
```

현재 주제에 적용할 때 P2는 `recording team = farm`이라고 자동으로 채우지 않는다. P3는 `이미지 수 = 동물 수`라고 채우지 않는다. 메타데이터에서 독립 단위를 찾을 수 없으면 “불명”으로 남기고 확인 행동을 적는다.

**논문 한 편의 근거 노트.** 초록 요약과 연구 설계 평가는 별개로 기록한다.

```text
제목 / 저자 / 연도 / DOI / 원문 파일:
읽은 날짜 / 읽기 목적:
논문 유형 / 정정·철회·후속 검증 확인:

1. 질문: 저자가 실제로 답하려 한 것은?
2. 자료: 어느 동물·농장·기간·장비·조직·처리에서 왔는가?
3. n: 파일/이미지/세포 수와 독립 동물/돈방/코호트 수는 각각?
4. 라벨: 누가 무엇으로 정했으며, 내가 관심 있는 개념의 직접 측정인가?
5. 설계: 대조군, 무작위화, 눈가림, 교란 처리는?
6. 분할: 데이터 분리 전후에 어떤 전처리·증강·특징 선택을 했는가?
7. 선택: 모델/하이퍼파라미터를 어떤 자료로 선택했는가?
8. 결과: 가장 중요한 수치와 분모, 지표 정의, 불확실성은?
9. 근거: 위 결과의 원문 페이지·표·그림·코드 위치는?
10. 비교: 기준 모델과 같은 대상/정보/예산으로 비교했는가?
11. 대안: 이 결과를 설명할 수 있는 다른 이유는?
12. 한계: 보고하지 않은 것과 하지 않았다고 확인된 것을 구분했는가?
13. 재현: 데이터·코드·환경·설정이 있으며 무엇을 재현했는가?
14. 내 행동: 다음 실험 또는 원고 문장 하나를 어떻게 바꿀 것인가?

논문을 닫고 쓸 5문장:
이 논문이 묻는 것은 ...
직접 관측한 것은 ...
가장 결정적인 비교는 ...
남은 대안 설명은 ...
내 연구에서 할 일은 ...
```

**주장–근거 표.** 원고 문장마다 직접 근거를 연결한다. 원문에 없는 내용을 자연스러운 문장으로 만들어 채우지 않는다.

| 원고의 주장 | 원자료/원문 위치 | 관측 또는 계산 | 가정·해석 | 허용 범위 | 확인자·날짜 |
|---|---|---|---|---|---|
| 예: 특정 split에서 macro-F1이 높았다 | 실행 ID, 결과 파일의 행 | 실제 점수와 평가 대상 | 선택 과정·seed/그룹 변이 | 해당 데이터와 분할에 한정 | |
| 예: 자동 길이 측정이 수동과 일치한다 | 평가자 측정표·일치도 그림 | bias·오차·일치 한계 | 허용 오차의 근거 | 검증된 조직·배치·주령 | |

```text
설정 파일 / 환경 / 실행 명령:
예상 실행 시간·비용 / 중단 조건:
실제 실행 시간 / 로그 / 오류:
결과 파일 / 그림 생성 명령:

```

**AI에 실제 연구 코드를 맡길 때 쓸 프롬프트.** 다음 텍스트에 실제 경로와 질문을 채워 사용한다. 개념 학습과 핵심 구현 연습에는 [ML·DL 심화 과정](ml_dl_depth_plan.md)의 힌트 우선 튜터 프롬프트를 사용한다. 두 방식의 시간을 구분해 기록한다.

```text
나는 이 분석을 이해하면서 진행하는 석사 연구자다.
프로젝트의 AGENTS.md와 현재 분석 계획을 먼저 확인해라.
이번 작업은 [한 가지 기능]이며 연구 질문은 [질문]이다.
입력은 [경로·열·단위], 출력은 [경로·형식]이다.
독립 표본 단위는 [확인한 단위]이고 분할은 [방법]이다.

먼저 관측 사실·가정·미확인 항목을 구분해 정리해라.
입력→변환→출력의 흐름과 이 과정이 필요한 이유를 설명해라.
열이나 메타데이터가 없으면 추정해서 채우지 말고 누락을 표시해라.
내가 손으로 확인할 수 있는 5~10행 예제와 예상 결과를 먼저 보여줘라.
이번 과제에 필요한 최소 구현을 하고, 단위 오류·그룹 누수·결합 중복을
실제로 잡는 검사만 추가해라.
원자료를 변경하지 말고 별도 출력에 기록해라.
프로젝트의 환경·실행 예산·시험 자료 잠금 규칙을 적용해라.
소규모 결과를 확인한 다음, 정해진 범위 안에서만 본 분석으로 확장해라.

완료 시 다음을 제시해라:
1. 무엇을 계산했는지와 계산하지 못한 것
2. 각 입력/출력의 행 의미, shape, 단위
3. 핵심 함수가 생물학적 질문에 연결되는 이유
4. 실제로 수행한 검증과 그 결과
5. 실패 사례 및 아직 주장할 수 없는 것
6. 내가 다시 실행할 명령, 코드·설정·로그 경로
7. 내 이해를 확인하는 짧은 문제 3개
```

**AI를 논문 읽기 튜터로 쓸 때의 프롬프트.** 원문을 제공하고 결과를 대조한다.

```text
이 논문을 연구 설계 중심으로 함께 읽자.
먼저 질문, 관측 단위, 독립 표본, 라벨 생성, 분할,
모델 선택, 평가 지표, 외부 검증을 표로 정리해라.
모든 수치·핵심 주장에는 원문 페이지/표/그림 위치를 붙여라.
원문에 보고되지 않은 것은 ‘보고되지 않음’이라고 써라.
보고되지 않았다는 이유로 수행하지 않았다고 단정하지 마라.

저자의 결론, 원자료가 직접 지지하는 결론, 너의 추론을 구분해라.
가장 강한 대안 설명 2개와 이를 구별할 최소 실험을 제안해라.
내 프로젝트 [설명]에 가져올 수 있는 부분과 재검증할 부분을 알려줘라.
마지막에는 내가 직접 답할 질문 5개만 주고, 정답은 내 답변 후에 설명해라.
```

**AI 없이 이해를 확인할 문제.** 외워서 말하기보다 종이와 작은 표로 설명한다.

| 분야 | 문제 | 통과 증거 |
|---|---|---|
| 표본 단위 | 같은 돼지 10두에서 이미지 100장을 얻었다. 언제 n=100이 부적절한가? | 측정 단위·독립 동물·처리 배정 단위를 구분하고 분석안을 그림 |
| 분할 | val과 test의 이미지가 같다면 test 점수는 무엇을 의미하는가? | 모델 선택에 사용된 정보를 추적하고 새 평가 설계 제안 |
| 분류 | 불균형 자료에서 accuracy와 macro-F1의 판단이 달라지는 예는? | 2×2 혼동행렬을 만들고 직접 계산 |
| 일반화 | 녹음팀을 분리하면 반드시 농장 일반화를 증명하는가? | 팀·농장·연령·맥락의 관계와 남은 불확실성을 설명 |
| 조직 측정 | 모든 예측값이 실제보다 100µm 큰데 상관이 높을 수 있는가? | 직접 수치 예제와 일치도 그림을 만듦 |
| 전사체 | FPKM 표를 왜 raw count처럼 DESeq2에 넣으면 안 되는가? | 자료 생성·정규화·모형 입력의 차이 설명 |
| 다중검정 | 유전자 수가 많을 때 p<0.05만으로 고르면 무엇이 문제인가? | 기대되는 거짓 양성과 FDR의 의미를 설명 |
| 교란 | 처리군과 배치가 완전히 같으면 모형에 둘 다 넣어 해결할 수 있는가? | 식별 불가능성과 필요한 추가 자료를 설명 |
| 미생물군 | A균의 비율이 10%→20%이면 A균이 두 배로 늘었는가? | 총량이 다른 반례를 만듦 |
| 해석 | 다른 돼지에서 수집한 조직 이미지와 RNA-seq를 임의로 짝지을 수 있는가? | 개체 대응·가설 생성·검증의 차이를 설명 |

**투고 직전 확인표.** 모든 항목이 모든 논문에 적용되는 것은 아니다. 해당 없음에는 이유를 적는다.

- [ ] 주 질문과 가장 중요한 결론이 일치한다.
- [ ] 실제 표본 수, 독립 단위, 반복 측정 구조가 명확하다.
- [ ] 이미 탐색한 자료를 미사용 시험 자료라고 쓰지 않았다.
- [ ] 전처리와 모델 선택에 평가 자료가 섞이지 않았다.
- [ ] 분할·제외 기준·주석·자료 버전을 추적할 수 있다.
- [ ] 기준 방법과 공정한 비교를 했고 실패한 조건도 보고했다.
- [ ] 불확실성의 계산 단위가 실제 자료 구조와 맞는다.
- [ ] 조직 측정은 전문가 기준과 단위·오차·실패율을 검증했다.
- [ ] 통계적 차이, 실질적 의미, 인과 주장을 구별했다.
- [ ] 원문 대조 없이 AI가 만든 수치·인용·주장을 남기지 않았다.
- [ ] 독립된 사람이 핵심 표 또는 그림을 재현했다.
- [ ] 논문 간 공통 자료·방법·관련 원고를 투명하게 설명했다.
- [ ] 공동저자가 원고를 검토하고 저자 역할·자료 사용을 확인했다.
- [ ] 저널의 현재 범위·논문 유형·정책·등재·비용을 확인했다.
- [ ] 제출 원고·코드·설정·데이터 버전의 사본을 고정했다.
