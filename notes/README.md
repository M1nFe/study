**학습 노트 작성 방법**

각 주차에 `week-01/`처럼 폴더를 만들고 `concepts.md`, `exercises.md`, `experiment.md`, `weekly-report.md`를 작성한다. 코드는 필요할 때 같은 주차에 추가한다. [주간 보고서 양식](../templates/weekly-report.md)과 [52주 계획](../curriculum.md)을 참고한다.

개념 노트에는 정의·가정·단위·작은 예제를, 풀이에는 첫 시도·오류·수정·다시 푼 결과를, 실험 기록에는 환경·명령·입력·출력·검증·실패를 남긴다. 이미 알려진 답을 복사한 파일과 직접 해결한 결과를 구분한다.

현재는 계획만 작성된 상태다. 향후 자신의 풀이를 작성한 뒤 진도표를 갱신한다. 공개 가능한 학습용 예제만 이 폴더에 저장하고 미공개 실제 연구 기록은 로컬 `.local/`에 둔다.
