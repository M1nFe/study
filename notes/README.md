**실험·분석·글쓰기 노트 작성법**

각 주에 `week-01/` 폴더를 만들고 `protocol.md`, `analysis.md`, `research-paragraph.md`, `weekly-report.md`, `essays/`를 작성한다. 기존 `concepts.md`·`exercises.md`·`experiment.md`를 이미 사용했다면 지우지 말고 연결한다.

- [프로토콜 카드](../templates/protocol-card.md): 원리·조건 근거·대조·QC·실제 수행 여부.
- [숙련표](../templates/skill-matrix.md): L1 이해·L2 지도하·L3 독립·L4 오류 진단의 실제 증거.
- [논술 기록](../templates/essay-review.md): 학교·연도·문항·공식 링크·개요·초고·피드백·퇴고·수정 이유.
- [주간 보고서](../templates/weekly-report.md): 실제 60시간 배분·근거·막힌 점·다음 행동.

분석 노트에는 입력·단위·대조·가정·실행·검산·실패를 적는다. 연구 문단에는 실제 관측과 해석·대안 설명을 구분한다. AI나 예시답안의 도움을 받은 부분을 기록한다. [52주 계획](../curriculum.md)과 [진도표](../progress.md)는 실제 증거를 남긴 뒤 갱신한다.

공개 가능한 학습 예제·자신의 글만 공개 노트에 남긴다. 실제 미공개 시료·실험·심사 기록은 `.local/`에 둔다. 기출 제시문·교재 원문 전체를 공개 복제하지 않는다. 계획 폴더가 생겼다는 사실은 실험 수행이나 글쓰기 완료를 뜻하지 않는다.
