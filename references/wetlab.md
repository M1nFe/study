**실험 원리·프로토콜·검증 자료**

2026-10-01 확인. [52주 계획](../curriculum.md)의 주제별 읽기 목록이다. 교재·가이드·개별 제품 매뉴얼·연구실 SOP는 역할이 다르다. 여기 적은 제목은 읽을 범위이며 임의의 시약 조건이나 실행 절차를 확정하지 않는다. 실제 시료·장비·제품에 맞는 판본과 담당 지도자를 첫 주에 기록한다.

| 약어 | 공식 자료 | 읽는 방법 |
|---|---|---|
| MBOC | [Molecular Biology of the Cell, 7판](https://seagull.wwnorton.com/molecularbiologycell) | 세포·단백질·핵산·발현·막·신호·상피·세포주기의 해당 주제. 원리의 중심 교재. |
| MSMB | [Modern Statistics for Modern Biology](https://www.huber.embl.de/msmb/index.html) | 2장 모형, 6장 검정, 8장 count/GLM, 9장 이질 자료, 11장 이미지, 12장 지도학습, 13장 설계, 14장 일치도에서 필요한 절. |
| NRC | [Nutrient Requirements of Swine, 11차 개정판](https://www.nationalacademies.org/read/13298) | 2012판. 소화·영양·성장 관련 주제. 분자 지표와 실제 축산 질문을 연결. 최신 사양표준과 동일시하지 않음. |
| BDS | [Bioinformatics Data Skills](https://vincebuffalo.com/book/) | 자료 사전·형식·프로젝트 관리·재현성·Git의 해당 주제. |
| ARRIVE | [ARRIVE 2.0](https://arriveguidelines.org/arrive-guidelines) · [NC3Rs 설계 자원](https://nc3rs.org.uk/3rs-resources/reliable-reproducible-and-rigorous-research) | 동물 연구의 설계·분석·보고에서 독립 단위와 편향 관리 등 필요한 항목을 대조. |
| MIQE | [MIQE 2.0, 2025](https://pubmed.ncbi.nlm.nih.gov/40272429/) · [원문](https://academic.oup.com/clinchem/article/71/6/634/8119148) | RT-qPCR의 표본·assay 검증·정규화·분석·보고를 확인. 연구실 기존 방식과 개정 권고의 차이를 지도자와 검토. |
| LEICA | [조직 처리 교육자료](https://www.leicabiosystems.com/us/knowledge-pathway/sample-preparation/page-1/) · [고정의 원리](https://www.leicabiosystems.com/us/knowledge-pathway/fixation-and-fixatives-1-the-process-of-fixation-and-the-nature-of-fixatives/) | 고정·처리·절단 관련 설명을 읽고 실제 조직 SOP의 각 단계와 대조. |
| CST | [공식 프로토콜 모음](https://www.cellsignal.com/learn-and-support/protocols) · [Western](https://www.cellsignal.com/learn-and-support/protocols/protocol-western) · [IF](https://www.cellsignal.com/learn-and-support/protocols/protocol-if-cell-based-imaging) | 응용과 제품별 조건·검증 범위를 확인. 다른 종·조직·항체에서 그대로 성립한다고 가정하지 않음. |

| ATCC | [Cell Line Authentication Test Recommendations](https://www.atcc.org/resources/technical-documents/cell-line-authentication-test-recommendations) | 세포주 정체성과 오염 검사 개념. 사용 종에 적합한 확인법을 지도자와 선택. |

ISLP·UDL·U-Net·Bland–Altman·CAL·PIGRNA·DESeq2·Salmon 원저의 링크는 [기존 교재·논문 목록](books.md)에 있다. 기존 수학·DL 자료는 필요한 부분의 보충 자료로 사용한다.

**첫 주에 채울 실제 자료.** 조직 처리·염색·촬영·형태 측정 SOP, 피펫·저울·현미경 매뉴얼, 선택한 RNA 추출·RT·qPCR 제품의 매뉴얼, 실제 항체·세포주·기능 assay 자료를 연구실에서 확인한다. 제품이 정해지지 않은 상태에서 특정 제품의 수치 조건을 공부 계획에 확정하지 않는다. 파일명·버전·확인 날짜는 [프로토콜 카드](../templates/protocol-card.md)에 기록한다.

문헌의 절차를 요약한 것과 손으로 수행해 숙련한 것은 구별한다. 교재·논문·매뉴얼 전체를 이 저장소에 재배포하지 않는다.
