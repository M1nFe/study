2026-10-08 개정. 현재 우선순위는 **SoundWel 공개 음성으로 분석 방법을 검증하고, 행동 변화와 회복 과정을 관찰할 후속 연구를 준비하는 것**이다. Lee 등의 2024년 이유 스트레스·놀람 반응 논문을 생물학적 출발점으로 삼는다.

**오늘 시작:** [연구 가이드맵](docs/roadmap.md) → [Lee 2024 연결 설계](docs/lee2024_bridge.md) → [첫 72시간·2주 실행표](docs/soundwel_execution.md). 첫 산출물은 데이터 단위표와 Methods 초안이다. 기초 공부를 전부 끝낸 뒤 분석을 시작하는 일정은 아니다.

**2026-10-09 실험 설계:** [가설·통계·현장 관찰 프로토콜](docs/experimental_design.md)에 표본·모형·GBA 주지표·재표집·18일 수집안을 구체화했다. S1은 기존 부록에서 발견해 작업 사본으로 연결했으며 다음 과제는 충돌·그룹·분할 검증이다. 모델 본 분석은 아직 실행하지 않았다. 구체적 분석 규칙은 이 프로토콜을 우선한다.

**주 60시간:** 분석·검증 24h, 필요한 생물학·통계 8h, 원문·원고·회의 10h, 기존 실험실 업무·현장 준비 10h, 인문논술 8h. 같은 시간을 중복 계산하지 않는다. 기존 실험·강의·조교 업무가 늘면 일정을 조정한다. 논술 주 3회는 [기존 방법](docs/writing_practice.md)을 유지한다.

첫 원고는 맥락과 연관된 음향 특징이 그룹 구조와 평가 조건에 얼마나 민감한지 묻는다. 8주는 투고 준비를 점검할 목표 기간이며 게재나 분석 성공의 보장이 아니다. SoundWel의 맥락 라벨을 회복탄력성 정답으로 바꾸지 않는다. 한 돈방 현장 관찰은 연속 음영상 측정의 실행 가능성을 확인하는 후속 파일럿이다.

**장기 기초 과정:** [커리큘럼 후반의 52주 표](curriculum.md)와 `weeks/week-01.md`~`week-52.md`는 조직·분자 실험·AI·글쓰기 참고 과정이다. 집중 과정의 1주차와 기초 과정의 1주차는 다르다. 두 시간표를 동시에 60시간씩 수행하지 않는다.
