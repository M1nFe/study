**돼지 음향·행동 연구: 분석 검증부터 논문 초안까지**

2026-10-12 개정. 현재 우선순위는 **현장 수집 없이 SoundWel의 특정 맥락 묶음 간 전이를 검증하고 원고를 쓰는 것**이다. Lee 등의 2024년 이유 스트레스·놀람 반응 논문에서 상황 간 지표의 일반화라는 질문을 가져온다.

**오늘 시작:** [현장 없는 맥락 전이 실험](docs/context_transfer_design.md) → [현재 커리큘럼](curriculum.md). 같은 평가 발성에 K/U 두 학습 조건과 지속시간/네 특징을 비교한다. 첫 산출물은 원 맥락·동복·원 녹음 감사표와 고정 분할이다.

**현재 실험 설계:** [10월 12일 프로토콜](docs/context_transfer_design.md)을 우선한다. 일부 개체 ID의 의미가 불확실하고 양성 평가가 다섯 동복 블록에 집중되어, 동복 제외 5-fold·20회 기본 적합의 탐색 연구로 범위를 정했다. 모델 본 분석은 아직 실행하지 않았다. [10월 9일 설계](docs/experimental_design.md)는 이전 분석 질문과 현장 후속안으로 보존한다.

**주 60시간:** 분석·검증 24h, 필요한 생물학·통계 8h, 원문·원고·회의 10h, 기존 실험실 필수 업무 10h, 인문논술 8h. 같은 시간을 중복 계산하지 않는다. 기존 실험·강의·조교 업무가 늘면 일정을 조정한다. 논술 주 3회는 [기존 방법](docs/writing_practice.md)을 유지한다.

첫 원고는 동일한 평가 발성에서 학습 맥락의 구성이 음향 분류 성능을 얼마나 바꾸는지 묻는다. 8주는 투고 준비를 점검할 목표 기간이며 게재나 분석 성공의 보장이 아니다. SoundWel의 맥락 라벨을 회복탄력성 정답으로 바꾸지 않는다. 현장 관찰은 별도 후속 선택이며 이번 원고의 필수 자료가 아니다.

**장기 기초 과정:** [커리큘럼 후반의 52주 표](curriculum.md)와 `weeks/week-01.md`~`week-52.md`는 조직·분자 실험·AI·글쓰기 참고 과정이다. 집중 과정의 1주차와 기초 과정의 1주차는 다르다. 두 시간표를 동시에 60시간씩 수행하지 않는다. [기초 과정 진도](progress_foundation.md), [이전 로드맵](docs/roadmap_2026-10-01.md), [선택 ML·DL 심화](docs/ml_dl_depth_plan.md)는 보존한다. 친구용 [ML 입문 16주](friends/ml-beginner/README.md)는 별도 과정이다.

**공개 저장소 운영:** 학습 계획·일반화한 설계·공개 가능한 노트를 관리한다. 실제 분석은 기존 연구 엔진에서 실행하며 이 저장소에 엔진을 복제하지 않는다. 원자료·저자 제공 ID표·미공개 결과·개인 경로·공동저자 검토 기록은 Git 제외 대상인 `.local/` 또는 연구실 저장소에 둔다. 숫자와 완료 상태를 임의로 채우지 않는다.

[노트 안내](notes/README.md)를 따르고 커밋 전 `git diff`와 `git status`로 공개할 파일을 확인한다. 현재 실행 순서는 **2026-10-12 README·맥락 전이 프로토콜·커리큘럼**을 따른다. 보존한 과거 문서의 일정이 이를 덮어쓰지 않는다.
