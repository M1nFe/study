**돼지 음향·행동 연구: 공개자료 검증과 농장 수집에서 논문까지**

2026-10-15 개정. 연구는 두 트랙으로 진행한다. **SoundWel에서는 특정 맥락 묶음 간 전이를 검증해 첫 원고를 쓰고, 농장에서는 급이 전후 음성·행동을 관찰할 수 있는 자료를 확보한다.** Lee 등의 2024년 이유 스트레스·놀람 반응 논문에서 상황 간 지표의 일반화라는 질문을 가져오되, 서로 다른 자료를 회복탄력성의 같은 정답으로 취급하지 않는다.

**오늘 시작:** [전체 실험·수집 계획](docs/data_collection_master_plan.md) → [데이터 사전](docs/data_dictionary.md) → [현재 커리큘럼](curriculum.md). SoundWel 분석 규칙은 [10월 12일 맥락 전이 프로토콜](docs/context_transfer_design.md)을 따른다. 농장에서는 보유 카메라로 저장·음질·회수 시험을 먼저 한다.

**현재 상태:** SoundWel의 S1 연결·잠정 분할·학습량 매칭·완전 동일 음원 검사는 선행 작업으로 기록돼 있다. 최종 원 녹음 관계 확인과 분석용 분할 동결은 남아 있으며 **모델 본 분석은 아직 실행하지 않았다.** 일부 개체 ID의 의미가 불확실하고 양성 평가가 다섯 동복 블록에 집중되어 동복 제외 5-fold·20회 기본 적합의 탐색 연구로 범위를 정했다. [10월 9일 설계](docs/experimental_design.md)는 이전 분석 질문과 현장 후속안의 이력이다.

**주 60시간:** 분석·QC 24h는 보통 주에 SoundWel 18h와 농장 자료 QC·판독 6h로 나눈다. 필요한 생물학·통계 8h, 원문·원고·회의 10h, 기존 연구실 업무·현장 운영 10h, 인문논술 8h를 더한다. 이동·회수·복사·백업도 이 시간 안에 기록한다. 강의·조교·기존 실험이나 현장 업무가 늘면 분석 배분과 달력을 조정한다. 같은 시간을 중복 계산하거나 초과 근무를 전제하지 않는다. 논술 주 3회는 [기존 방법](docs/writing_practice.md)을 유지한다.

첫 원고는 동일한 평가 발성에서 학습 맥락의 구성이 음향 분류 성능을 얼마나 바꾸는지 묻는다. 농장 자료는 별도 측정 파일럿이며 첫 원고의 필수 자료가 아니다. 현장 수집은 두 인접 돈방을 카메라의 내장 마이크·SD 저장으로 관찰하고, ATTD나 별도 녹음기를 추가하지 않는 계획이다. 처리당 돈방 하나의 시간 반복을 독립 처리 반복으로 세지 않는다. 농장 기준선 수집일이 먼저 오면 재수집할 수 없는 관찰을 우선하고 SoundWel 일정을 옮긴다.

8주는 원고 검토·투고 준비를 점검할 목표 기간이다. 실제 기여와 데이터 품질에 따라 조정하며 게재나 분석 성공을 보장하지 않는다.

**장기 기초 과정:** [커리큘럼 후반의 52주 표](curriculum.md)와 `weeks/week-01.md`~`week-52.md`는 조직·분자 실험·AI·글쓰기 참고 과정이다. 집중 과정의 1주차와 기초 과정의 1주차는 다르다. 두 시간표를 동시에 60시간씩 수행하지 않는다. [기초 과정 진도](progress_foundation.md), [이전 로드맵](docs/roadmap_2026-10-01.md), [선택 ML·DL 심화](docs/ml_dl_depth_plan.md)는 보존한다. 친구용 [ML 입문 16주](friends/ml-beginner/README.md)는 별도 과정이다.

**공개 저장소 운영:** 학습 계획·일반화한 설계·빈 양식·공개 가능한 노트를 관리한다. 실제 분석은 기존 연구 엔진에서 실행하며 이 저장소에 엔진을 복제하지 않는다. 원자료·저자 제공 ID표·작성한 농장 대장·미공개 결과·개인 경로·공동저자 검토 기록은 Git 제외 대상인 `.local/` 또는 연구실 저장소에 둔다. 숫자와 완료 상태를 임의로 채우지 않는다.

[노트 안내](notes/README.md)를 따르고 커밋 전 `git diff`와 `git status`로 공개할 파일을 확인한다. 전체 일정과 농장 수집은 **2026-10-15 전체 계획**, SoundWel 분석 규칙은 **2026-10-12 맥락 전이 프로토콜**이 정본이다. 보존한 과거 문서의 일정이 이를 덮어쓰지 않는다.
