**축산 생물학·실험·AI 활용·글쓰기 석사 연구 스터디**

석사 2학기부터 주 60시간으로 운영하는 52주 계획이다. 목표는 **생물학적 질문을 세우고, 실험의 원리와 오류를 이해하며, 필요한 AI를 선택·적용·검증하고, 근거 있는 글로 설명하는 연구자**가 되는 것이다. 2026-10-01에 사용자의 연구 지향과 교수님의 실험 지도 지원을 반영해 개정했다.

**바로 시작하기.** [1주차](weeks/week-01.md)에서 주력 기법·지도 담당자·시료·SOP를 확인하고 현재 숙련을 진단한다. [연구 방향과 우선순위](docs/research_orientation.md)를 읽은 뒤 [진도표](progress.md)에 실제 증거를 기록한다.

- [52주 전체 계획](curriculum.md): 매주 실험·교재 범위·프로토콜 원리·대조군·QC·필요한 AI·논술 3회.
- [실험 중심 연구 방향](docs/research_orientation.md): 역할, 최소 AI 역량, 숙련 기준, 실험에서 모델 과제로 연결하는 예.
- [인문논술 연습법](docs/writing_practice.md): 연세·한양·서강·중앙·건국 순환, 초고·피드백·퇴고, 연구 문단 연결.

- [선택 ML·DL 심화 자료](docs/ml_dl_depth_plan.md): 필요할 때 해당 부분을 참고. 이전의 주 20시간 ML 시간표는 현재 필수 일정이 아니다.

별도 입문 과정: [완전 초보 친구를 위한 ML 16주](friends/ml-beginner/README.md). 코딩 기초부터 시작하는 주 8시간 과정이며 위 연구자용 52주 계획과 별개다.

**주 60시간.** 같은 시간을 중복 계산하지 않는다.

| 활동 | 시간 |
|---|---:|
| Wetlab·주력 연구 수행·측정·QC | 22h |
| 생물학·프로토콜 원리 | 10h |
| 실험 설계·통계·생물정보학 | 8h |
| 필요한 AI·코딩·분석 검증 | 6h |
| 논문 읽기·연구 글쓰기·회의 | 6h |
| 인문논술·첨삭·퇴고 | 8h |
| 합계 | 60h |

월·목·토에 독립적인 서술형 논제 한 개씩 초고부터 퇴고까지 150분을 쓴다. 학교를 주 경계에서도 순환하고, 나머지 30분에는 연구 문단을 쓴다. 학교별 전 시험지 한 회를 뜻하는 경우에는 실제 분량에 맞춰 시간을 다시 배분한다. 강의·조교 업무가 60시간에 포함되면 먼저 차감한다. 실험 일정에 맞춰 요일 블록은 이동할 수 있다.

**1년의 순서.** 1~12주는 실험 기본기와 조직·현미경·측정, 13~20주는 RNA·RT-qPCR, 21~28주는 단백질·세포 모델, 29~42주는 생물정보학·AI 적용·독립 검증, 43~52주는 실패 진단·심사·재현·후속 연구를 중심으로 한다. 처음 배운 기법은 이후 연구 블록에서 반복한다. 모든 기법을 경험한 것과 독립 숙련을 구분한다.

논문 목표는 기존 리뷰 1편과 원저 2편의 투고를 잠정 유지하고 4주차에 교수님과 자료·기여·시간을 재검토한다. 실험 학습마다 새 논문을 추가하지 않는다. 투고·게재 승인·학위 인정은 별도로 기록한다. 계획은 예정 사항이며 실제 결과나 수료 실적이 아니다.

**저장소 사용.** [노트 작성법](notes/README.md)에 따라 개인 기록을 만든다. 커밋 전 `git diff`와 `git status`를 확인하고, 공개할 노트만 명시적으로 추가한다. 예: `git add notes/week-01` 후 `git commit -m "study: record week 01 evidence"`. 완료 표시는 실제 풀이·수행·검증 근거가 있을 때만 한다.

실제 시료·미공개 실험·개인 경로·비공개 심사 기록은 Git에서 제외한 로컬 `.local/`에 보관한다. 공개 저장소에는 학습 계획·일반화한 설계·공개 가능한 노트를 남긴다. 교재·논문·입시 제시문 전체를 재배포하지 않는다. 기존 계획은 Git 이력과 로컬 보관본에 남아 있다.
