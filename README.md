**축산 AI·바이오인포매틱스 석사 연구 스터디**

석사 2학기차부터 주 60시간을 기준으로 ML·DL 기초, 생물정보학, 축산 연구를 연결하는 52주 계획이다. 논문 목표는 우선 리뷰 1편과 원저 2편의 1년 내 투고로 둔다. 게재 승인과 학위 인정은 별도로 확인한다. 계획과 과제는 예정 사항이며 연구 결과나 수료 실적이 아니다.

**바로 시작하기.** [1주차 계획](weeks/week-01.md)을 열고, [90분 진단이 포함된 심화 가이드](docs/ml_dl_depth_plan.md)의 진단 문제를 먼저 푼다. 실제 시작일을 기록하고 [진도표](progress.md)를 갱신한다.

- [52주 전체 교재·과제 목차](curriculum.md): 매주 읽을 범위, 월~토 순서, 자체 문제, 구현·검증, 생물학 연결, 완료 기준.
- [연간 연구 로드맵](docs/roadmap.md): 세 논문의 질문·검증·월별 목표.
- [ML·DL 심화 과정](docs/ml_dl_depth_plan.md): 설명·유도·구현·검증·연구 적용의 기준.
- [연구 실행 워크북](docs/research_workbook.md): 문헌 읽기, 실험 계획, AI 튜터와 코딩 프롬프트.
- [교재와 공식 자료](references/books.md): 판본과 공개 접근 경로.
- [주간 보고서 양식](templates/weekly-report.md), [노트 작성 방법](notes/README.md).

**시간 배분.** 아래 활동은 서로 중복 계산하지 않는다. 강의·조교 업무가 주 60시간에 포함된다면 먼저 그 시간을 차감한다.

| 활동 | 1~16주 | 17~52주 |
|---|---:|---:|
| ML·DL·통계 이론과 수학 | 12h | 6h |
| 학습용 핵심 구현 | 8h | 4h |
| 축산·생물학·오믹스 | 6h | 8h |
| 연구 논문 읽기 | 6h | 6h |
| 실제 프로젝트·측정·QC | 22h | 28h |
| 글·그림·회의·회고 | 6h | 8h |
| 합계 | 60h | 60h |

**자료를 읽는 기준.** 주차별 주교재를 먼저 읽고 나머지는 지정 소절만 보충한다. 처음에는 답을 보지 않고 시도한 뒤, AI에는 최소 힌트와 오류 진단을 요청한다. 하루 뒤 조건을 바꿔 다시 설명하거나 구현한다. 4·8·12·16주와 분기 말에 독립적인 설명·유도·검증을 점검한다.

계획 문서끼리 순서가 다르면 구체적인 실행은 `weeks/`를 따른다. `docs/`는 배경·연구 목표·방법의 참고 문서다. 주차별 실험과 투고는 데이터·측정·검증 조건이 충족되어야 진행한다. 일정 때문에 독립 평가를 생략하거나 완료 상태를 미리 표시하지 않는다.

**저장소 사용.** 주차 문서는 직접 수정할 수 있는 Markdown이다. 학습 노트는 `notes/week-01/`처럼 만들고 개념·풀이·실험·회고를 구분한다. 커밋 전 `git diff`와 `git status`를 확인하고, 해당 주차의 노트만 명시적으로 추가한다. 예를 들어 작성이 끝난 `notes/week-01`을 `git add notes/week-01`로 추가한 뒤 `git commit -m "study: complete week 01 exercises"`로 기록한다. 완료했다고 적기 전에 실제 풀이와 검증 근거를 남긴다.

이 저장소의 공개 문서는 학습 계획과 일반화한 연구 설계다. 개인 맥북 경로, 미공개 실험 점검 기록, 원본 사본은 로컬 `.local/`에 보관하고 Git에서 제외한다. 원자료·모델 가중치·비공개 심사 기록을 학습 노트와 함께 올리지 않는다. 저작권이 있는 교재·논문 원문은 링크로 참조한다.

작성·자료 확인: 2026-09-29. 주차 시작일은 학사 일정에 맞춰 정한다. 교재의 판본이나 공식 웹 자료가 바뀌면 장·절 제목과 실제 사용 버전을 기록한다.
